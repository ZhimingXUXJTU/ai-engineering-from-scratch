## 概念的核心概念

### 工作流程与代理人

- **Workflow.**工程师拥有图表.
  翻译: 中文**工作流。**通过预定义代码路径编排的LLM 和工具──工程师拥有图──
- **Agent.**士们动态地指导自己的工具,采取自己的步骤.
  翻译: 中文**Agent。**士 动态指导自己的工具和步骤――模型拥有图――

工作流程便宜,快速,更容易调试. 代理人解锁了无限的问题, 但使失败模式更难推理.

>  **【类比】**工作流程与代理 像地铁与自驾:地铁:工作流程)路线固定,便宜,可靠,但你只能去站点;自驾代理)灵活,能去任何地方,但可能迷路,烧油,出车祸――日常通勤选地铁 (工作流程),探索未知地区选自驾代理) ⋅新手最常见的错误是"所有任务都自驾"

> 两者都有其武之地――工作流更便宜、更快、更容易调试――代理 解锁开放式问题但使失败模式更难推理――

### 增强的法定律师

基础五种模式:一个LLM,有三个功能,包括搜索 (检索),工具 (行动),内存 (持久性).任何API调用都可以使用这些.

> 所有五种模式的基础:一个LLM 配备三种能力搜索检索工具行动记忆持久化任何API调用都可以使用这些

### 五种模式

1. **Prompt chaining.**输出调用1是输入调用2. 使用当任务具有清洁的线性分解时. 选项间的程序门.
   翻译: 中文**提示链。**调用1的输出是调用2的输入. 当任务有清晰的线性分解时使用.
2. **Routing.**类别的LLM选择下游LLM或工具. 使用当不同的输入需要不同的处理 (级-1支持与退款与错误与销售).
   翻译: 中文**路由。**分类器 LLM 选择调用哪个下游 LLM 或工具──当不同类型的输入需要不同处理时使用──
3. **Parallelization.**运行N LLM同时调用,总结结果.两个形式:分区 (不同块) 和投票 (相同的提示,N运行,多数/合成).
   翻译: 中文**并行化。**并发运行 N 个 LLM 调用,聚合结果──两种形式:分段(不同块) 和投票(同提示,N 次运行,多数/综合)──
4. **Orchestrator-workers.**管弦乐师 (LLM) 动态决定哪些工人 (也叫做LLM) 运行并合成他们的产量.类似于代理循环,但管弦乐师不会无限时间循环.
   翻译: 中文**编排器-工作者。**编排器 LLM 动态决定运行哪些工作者(也是 LLM)并综合其输出――类似于代理循环,但编排器不会无限循环――
5. **Evaluator-optimizer.**一个法学士提出答案,另一个法学士评估它. 连续进行直到评估者通过. 这就是自我清理 (课程05).
   翻译: 中文**评估器-优化器。**一个法师提出答案,另一个法师评估它.

### 工作流程比代理人更好

> 工作流优于代理的场景:

- **Predictable tasks.**如果您能列出步骤,那么您应该.
  翻译: 中文**可预测任务。**如果你能举个步骤,你就应该举一个步骤.
- **Cost-bound tasks.**工作流程有限步骤数量; 代理人可以螺旋.
  翻译: 中文**成本受限任务。**工作流有有限的步骤;代理可能失控.
- **Compliance-bound tasks.**审计人员希望阅读图表,而不是从轨迹中推断.
  翻译: 中文**合规受限任务。**审计员想阅读图,而不是从轨迹推断.

### 代理人比工作流程更好

> 优于工作流的场景:

- **Open-ended research.**接下来的步骤是什么,取决于最后的步骤是什么.
  翻译: 中文**开放式研究。**当下一步决定了下一步回归了什么.
- **Variable-length tasks.**工作时间分钟到几个小时,步骤数量不清楚.
  翻译: 中文**可变长度任务。**几分钟到几小时的工作,步骤数不清楚.
- **Novel domains.**首先要编码,然后要编码.
  翻译: 中文**新领域。**当你还不知道正确的工作流程时,先探索,后编.

## 关键词 快速查找表

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| 术语 | 通俗说法 | 实际含义 |
| Workflow | "Predefined flow" / "预定义流程" | Engineer-owned graph of LLM and tool calls / 工程师拥有的 LLM 和工具调用图 |
| Agent | "Autonomous AI" / "自主 AI" | Model-owned graph; dynamic tool direction / 模型拥有的图；动态工具指导 |
| Augmented LLM | "LLM with tools" / "带工具的 LLM" | LLM + search + tools + memory; the atomic unit / LLM + 搜索 + 工具 + 记忆；原子单元 |
| Prompt chaining | "Sequential calls" / "串行调用" | Output of call N is input to call N+1 / 调用 N 的输出是调用 N+1 的输入 |
| Routing | "Classifier dispatch" / "分类分派" | Pick which chain/model handles the input / 选择哪个链/模型处理输入 |
| Parallelization | "Fan out" / "扇出" | N concurrent calls; aggregate by sectioning or voting / N 个并发调用；按分段或投票聚合 |
| Orchestrator-workers | "Dispatcher agent" / "分派 Agent" | Orchestrator LLM picks specialist LLMs dynamically / 编排器 LLM 动态选择专家 LLM |
| Evaluator-optimizer | "Proposer + judge" / "提议者 + 评判者" | Iterate until evaluator passes; Self-Refine generalized / 迭代直到评估器通过；Self-Refine 的泛化 |

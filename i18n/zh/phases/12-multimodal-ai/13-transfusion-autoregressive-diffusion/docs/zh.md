# 转移:自归文本和扩散图像

> 马和Emu3都会投注于单独的代币. 它们有效,但量子化瓶可见 图像质量高原在连续空间扩散模型下面. 转血 (Meta, Zhou等同,2024年8月) 采取相反的选择:保持图像连续,完全放弃VQ-VAE,并训练一个变压器, 文字代币可以预测下一个代币. 图像补丁产生流量匹配/扩散损失. 两者都能达到相同的重量. 基于稳定扩散3 (MMDiT) 的架构是近亲的. 这一课上读了转论文, 构建了一个玩具两损训练器, 并追踪了一个变压器可以做这两项工作的注意力面具.

> **【中文解读】**转移 (Meta,2024年8月) 选择与Chameleon/Emu3相反的路径:保持图像为连续表示,不用VQ-VAE,使用一个变压器 同时运行两个损失文本代币 用下一个代币预测,图像补丁用流匹配/扩散损失──稳定扩散3的MMDiT架构就是近亲──

> **【拓展：双损失训练的工程挑战】**输血的核心难点在于平衡两个数值尺度的不同损失函数――NTP 损失和扩散 MSE 损失的量级差异可能导致损失主导训练――实际部署中需要仔细调整损失权重――MMDiT 通过模态特定权重缓解了这个问题――

## 问题背景

离散与连续图像代币辩论比LLM更老.连续表示 (原始像素,VAE隐藏) 保存细节.离散代币 (VQ指数) 适合变压器的本土词汇,但在量化步骤中丢失细节.

> 离散与连续图像代币的争论比LLM更早──连续表示(原始像素、VAE 潜变量) 保留细节──离散代币(VQ索引) 适合变压器的原生词汇表,但在量化步骤中损失细节──

马里昂/Emu3是个分别的:一个损失,一个架构,但图像忠诚度被标记器质量限制.

> 马里昂/Emu3 选择离散:一个损失,一个构建,但图像保真度仅限于分词器质量──

扩散模型持续:图像质量非常优异,但与LLM的模型是独立的,噪音时间表工程复杂,并没有与文字生成的清洁集成.

> 扩散模型选择连续:卓越的图像质量,但与LLM是独立模型,需要复杂的噪音调节工程,无法与文本生成干净集成.

输血问:我们可以有两者吗? 保持图像连续,仍然训练一个模型,使用两个损失成一个梯度步骤.

> 输血 问题:能否兼得两者?保持图像连续,仍然训练一个模型,用两个损失拼接到一个梯度步骤中――

### 注意面具:因果性文本+双向图像

文字代币必须是因果性的. 您不能让文字代币在未来的文本中进行处理,或者教师强制休息. 图像补丁,然而,代表一个快照;它们应该在同一图像区块内双向地对待彼此.

> 文本代币必须是因果的不能让文本代币关注未来文本,否则教师强制会失败――但图像补丁代表一个快照;它们应该在同一图像块内双向关注彼此――

面具:

> 掩码:

```
M[i, j] = 1 if:
  (i is text and j is text and j <= i)   # causal for text
  OR (i is image and j is image and same_image_block(i, j))   # bidirectional within image
  OR (i is text and j is image and j < i_image_end)   # text attends to previous images
  OR (i is image and j is text and j < i_image_start)   # image attends to preceding text
```

作为一个区块三角形面具,用于训练和推断.

> 在训练和推理时实现为块三角掩码.

### 变压器内部的扩散损失

输出损失是标准的:添加噪音到图像补丁,要求模型预测噪音 (或清洁补丁,相等).输出版本使用流量匹配预测噪音到清洁的速度场.

> 扩散损失是标准的:给图像补丁 添加噪音,让模型预测噪音(或等价地预测干净补丁) ―― 输液 版本使用流匹配预测从噪音到干净的速度场――

在培训期间:
1. 对于每个图像补丁 x0 取一个随机时间步骤 t.
   中文翻译:对每个图像补丁 x0,采样随机时间步 t──
2. 样本噪音 ε,计算xt = (1-t) * x0 + t * ε (用于流量匹配的线性插射).
   中文翻译:采样噪声 ε,计算 xt = (1-t) * x0 + t * ε(流匹配的线性插值) 』
3. 变压器预测v_theta(xt,t);损失 = MSE(v_theta(xt,t), ε - x0).
   中文翻译:变压器 预测 v_theta(xt, t);损失 = MSE(v_theta(xt, t), ε - x0)。
4. 随着相同序列的文字 NTP 损失.
   中文翻译:与同序列的文本NTP 损失与反向传播.

在推断下,生成是:
- 文字代码:标准的自动回归样本.
  中文翻译:文本代币:标准自归采样。
- 图像补丁:基于先前的文本代码的扩散样本循环 (典型的10-30步).
  中文翻译:图像补丁:以先前文本代币 为条件的扩散采样循环(通常是10-30步) ⋅

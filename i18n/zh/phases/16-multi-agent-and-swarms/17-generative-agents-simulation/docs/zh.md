## 概念的核心概念

### 三个组成部分

**Memory stream.**每条条目都有时间,类型,描述 (自然语言) 和衍生的元数据:**recency**现在**importance**(经纪人自行评价1-10),**relevance**(与当前查询相似的可索数).

> **记忆流。**一个只添加的观察,行动,反思和计划日志. 每条条都有时间,类型,描述,自然语言和派生元数据:**时效性**,我知道.**重要性**经验人员**相关性**(与当前查询的余弦相似度)

```
[2026-02-14 09:12:03] observation: Isabella Rodriguez asked me if I like jazz
[2026-02-14 09:14:22] reflection:   I enjoy long conversations about music
[2026-02-14 10:05:00] plan:         Attend Isabella's Valentine's Day party tonight
```

记忆检索组合了三个分数:`score = w_recency * e^(-decay * age) + w_importance * importance + w_relevance * cos_sim`现在的提示.

**Reflection.**定期 (每一个N记忆或重要事件),代理从最近的记忆中生成更高级的合成.反思条目回到流中,像其他任何记忆一样可回收.这就是代理建立"理解"的方法.

> **反思。**定期(每一条记忆或在重要事件中),代理从最近的记忆中产生高阶综合性――反思条目回到流中,像其他记忆一样可检查――这是代理建立"理解"的方式架构中等于长期信念――

**Plan.**首先,一个日级计划在大小的时间 ("去工作,和克劳斯吃晚饭").然后是小时级计划.然后是行动级计划.计划可修改:当观察与计划相矛盾时,代理重新规划受影响的部分.

> **计划。**自顶向下分解──首先,粗略的日级计划 ((上班,和克劳斯 共进晚餐")──然后是小时级计划──然后是动作级计划──计划是可修改的:当观察与计划矛盾时,代理重新规划受影响的部分──

### 为什么三者都重要 (摘除)

帕克等人运行了对观测,反思和计划的每一个减法.

> 帕克等进行消融实验,分别抛弃观察,反思和计划.

- 没有**observation**代理忽略了背景,并以旧信念行动.
  中文翻译:没有**观察**根据过去的信念行动.
- 没有**reflection**代理人不能形成更高层次的信念; 相互作用保持浅.
  中文翻译:没有**反思**代理人不能形成高阶信念;交互保持浅层――
- 没有**plan**行为变得反应噪音,目标消失.
  中文翻译:没有**计划**行为变成反应性噪音;目标消散.

人类评级的可信度分数是所有三项中最高的;

> 人类评分者可信度分数在三者齐全时最高;消除任何产生可测量的退化.

### 记录的故障模式

帕克等人明确记录:

> 帕克等明确记录:

- **Spatial norm errors.**经纪人走进封闭的商店.经纪人试图使用同一个人用浴室.经纪人在不用于吃饭的房间里吃饭.模型不仅仅是从环境中推断社会-身体规范.
  翻译: 中文**空间规范错误。**代理走进关闭的商店. 代理试图使用同一个单人浴室. 代理在非用餐室用餐. 模型不能仅仅从环境推断社会物理规范.
- **Memory overflow.**实用补救方法:定期缩小记忆 (总结和剪辑) 和低重量的输入的衰退.
  翻译: 中文**记忆溢出。**实际补救:定期记忆压缩 (摘要和修剪) 和低重要性条目的衰退.
- **Reflection hallucination.**缓解:在反射提示中包含源记忆ID,并在检索时验证.
  翻译: 中文**反思幻觉。**反思可能发明记忆流中不存在的关系――缓解:在反思提示中包含的记忆 ID 并在检查时验证――

这些是生产相关的故障模式:任何2026年代理模拟都继承它们.

> 这些都是与生产相关的失败模式:任何2026年的代理人都将继承它们.

### 执行三要素规则

1. **Memory is append-only.**修改是新的输入.
   翻译: 中文**记忆只追加。**永远不修改记忆条目――更正是新条目――
2. **Importance scores are cheap.**打电话给法师,在写作时给你一个10分的评分.
   翻译: 中文**重要性分数是廉价的。**写入时调用法师 评分 1-10──缓存分数──
3. **Retrieval is ranked, not filtered.**结合分数的顶级k;不要使用硬式过器 (它们失去了语境).
   翻译: 中文**检索是排序的，不是过滤的。**按综合分数取上-k;不要使用硬过(会丢失上下文) 』
4. **Reflection runs periodically.**触发器,未经处理的记忆重量的总量超过一个门 (例如150).
   翻译: 中文**反思定期运行。**当未处理记忆的重要性总和超过值 (例如 150) 当触发.
5. **Plans are revisable.**如果一个新的观察与一个计划相矛盾,只重建受影响的部分,而不是整个计划.
   翻译: 中文**计划可修订。**当新观察与计划矛盾时,只重生受影响的部分,而不是整个计划.

- `MemoryStream`仅添加日志,可检索最新/重要/相关性.
  翻译: 中文`MemoryStream`带时效性/重要性/相关性检索的仅额外日志
- `reflect(stream)` 关于最近重要记忆的剧本反思.
  翻译: 中文`reflect`对最近的重要记忆的脚本化反思
- `plan(agent_state)`基于当前信仰的日期和小时计划.
  翻译: 中文`plan` 基于当前信仰的日级和小时级计划.
- 剧情:五名代理人. 代理人1开始于下午5点的投球派对.

## 发射上线

生产模拟的规则:

- **Memory is the database.**选择一个真正的商店 (向量DB, Postgres) 尺度. 内存的SDLB是为原型.
  翻译: 中文**记忆是数据库。**在规模上选择真正的存储库,
- **Log the retrieval trace.**每次行动,记录驱动的最顶级记忆.这是你的调试能力.
  翻译: 中文**记录检索轨迹。**对于每一个动作,记录驱动它的顶级记忆.
- **Budget per-agent tokens.**每个代理的每次检索+反射+计划是O(k) LLM电话.
  翻译: 中文**预算每 Agent token。**每个代理 每个时间步骤检查 + 反思 + 计划是 O(k) 次 LLM 调用――N 个代理 × T 个时间步骤 × 每个时间步骤的数量可能让你的预算相形见──
- **Compact memory periodically.**简单地摘要,并剪除重要小项.
  翻译: 中文**定期压缩记忆。**摘要和修剪低重要性条目――保留策略是设计决策,而不是细节――
- **Detect spatial / social norm violations**建筑不会学到它们.
  翻译: 中文**显式检测空间/社会规范违规。**架构不会学习它们.

## 关键词 关键词

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Memory stream / 记忆流 | "The agent's diary" / "Agent 的日记" | Append-only log of observations, actions, reflections, plans. / 观察、行动、反思、计划的只追加日志。 |
| Recency / 时效性 | "How new is the memory" / "记忆有多新" | Exponential-decay score by age. / 按年龄的指数衰减分数。 |
| Importance / 重要性 | "How much does the agent care" / "Agent 有多在意" | Self-rated 1-10 at write time. Cached. / 写入时自评 1-10。已缓存。 |
| Relevance / 相关性 | "How related to the current query" / "与当前查询有多相关" | Cosine similarity (embedding-based). / 余弦相似度（基于嵌入）。 |
| Reflection / 反思 | "Higher-order belief" / "高阶信念" | Synthesis generated from recent memories, re-ingested as a new memory. / 从最近记忆生成的综合，作为新记忆重新摄入。 |
| Plan / 计划 | "Day/hour/action decomposition" / "日/小时/动作分解" | Top-down plan tree. Revisable when observations contradict. / 自顶向下计划树。观察矛盾时可修订。 |
| Smallville / 小镇 | "Park 2023's sandbox" / "Park 2023 的沙盒" | 25-agent simulation that produced the Valentine's Day emergence. / 25 个 Agent 的模拟，产生了情人节涌现。 |
| Believability / 可信度 | "The quality metric" / "质量指标" | Human-rater score for whether behavior seems like a plausible agent. / 人类评分者对行为是否像合理 Agent 的评分。 |

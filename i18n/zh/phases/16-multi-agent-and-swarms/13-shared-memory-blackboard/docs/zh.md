## 问题 问题引入

多代理系统需要一个代理分享事实的地方.一个字面上的选择是"通过信息",但这重新发明了共享状态,并增加了复制.另一个是"给每个人都提供全球日志",但全球日志会无限增长并很容易被毒害.第三个是"每代理的项目"可扩展但重于方案.

> 多代理 系统需要一个地方让代理共享事实. 一个字面选项是"在消息中传递一切东西"但这等于重新发明带额外复制的共享状态.另一个是"给每个人都一个全局日志".

它们是基于分布式系统的传统交易:便宜但脆弱 (信息),简单但不可扩展 (全球日志),可扩展但不稳定 (每个代理投影). 没有选择占主导地位.

> 三个选项追溯经典分布式系统权衡:廉价但脆弱的消息) 简单但不可扩展的全局日志) 可扩展但化的每一个代理投影) 没有选项占主导地位.

当一个代理人幻觉并写幻觉到共享状态时,每一个读到该状态的下游代理都会把幻觉作为事实.人类注意到的时候,推理链已经深入了五步,根源是有史以来第三个消息.调整多代理精度衰退比调整崩更难.

> 当其中一个代理 幻觉并将幻觉写入共享状态时,每个读取该状态的下游代理都将幻觉作为事实采纳.当人类注意到时,推理链已经有五步深,而根本原因是第三条消息.调试多代理 准确性衰退比调试崩更难.

记忆中毒会给你一个可信错误的报告.第一份可以在几秒钟内检测到;第二个可能需要几天的法医工作才能追溯到原始的幻觉.

> 崩给你堆跟踪――内存污染给你自信错误报告――第一是几秒钟可检测;第二是需要几天的检测工作才能追溯到原始幻觉――

这是一种记忆中毒.这是MAST类别中第二大记录的失败家族 (Cemri等人, arXiv:2503.13657) ,它是结构性的:任何没有来源的共享记忆设计和不可编写的验证器最终将显示它.

> 这就是内存污染. 它是MAST 分类法中第二大记录在案失败家族的事件中.

## 概念的核心概念

### 两个主要的拓物

**Full message pool.**每个代理都会阅读每一个消息.AutoGen GroupChat和MetaGPT都使用这种方法.简单,透明,可检查,但不会超过10个代理,因为每个代理的文本充满了其他代理的工作.

> **完整消息池。**每个代理 读取每条消息. 自动生成群Chat 和 MetaGPT 使用这种方式. 简单,透明,可检查,但不能扩展到约10个代理以上,因为每个代理的下文将填满其他代理的工作.

**Blackboard with subscription.**代理人表示对主题的兴趣;基板路线只传递相关信息.CA-MCP (arXiv:2601.11595) 和矩阵分散框架 (arXiv:2511.21686) 使用此.进一步扩展,但需要先前的方案设计,使订阅有意义.

> **带订阅的黑板。**代理声明对主题的兴趣;底层仅通过相关消息.CA-MCP(arXiv:2601.11595) 和Matrix 去中心化框架(arXiv:2511.21686) 使用这种方式.

> 没有代理 崩──没有测试失败──系统"工作"了──幻觉通过共享状态从一个代理的上下文进入每个下游代理的推理──

这就是为什么记忆中毒是诡诈性的:没有崩,没有错误,没有警告.系统产生了自信错误的报告.唯一的方法是从原始来源中重新提取每个事实,这打败了拥有代理的观点.

> 这就是为什么内存污染阴险:没有崩,没有错误,没有警告.系统产生自信错误报告.检测的唯一方法是从原始来源重新推向每个事实.

### 为什么这是结构性的

没有共享状态,A代理的幻觉仍然存在于A的背景下.下游代理会重新搜索或重新推导,可能会发现错误. 通过天真共享状态,A的背景成为每个人的背景,幻觉被洗成事实.

> 没有共享状态,Agent A的幻觉停留在A的上下文中. 下游Agent 会重新获取或重新推导并可能捕获错误.

问题不是一个共享国家本身**without provenance and without an independent verifier**三个减轻措施解决了这一问题:

> 问题不是共享状态本身,而是**没有来源追溯和没有独立验证器**共同状态:

每个缓解都针对不同的故障模式. 源源允许您追踪错误. 版本保存审计痕迹. 不可写的验证器提供独立检查. 它们一起形成了对毒品的深度防御.

> 每种缓解措施针对不同失败模式――来源追溯让你追溯错误――版本控制保留审计跟踪――不可写验证器提供独立检查――它们共同形成对污染的防护――

1. **Attribute provenance on every write.**根据什么提示,如果适用,代理引用哪个来源. 下游代理阅读怀疑,关键是来源.
   翻译: 中文**每次写入时归属来源。**共有状态中的每条目记录谁写的、何时、在什么提示下、以及(如果适用) 代理引用什么来源――下游 根据来源以怀疑态度阅读――
2. **Version writes; treat them as append-only.**修改是取代旧的新条目,而不是现场更新.
   翻译: 中文**版本化写入；视为仅追加。**修正是一个取代旧条目的新条条,不是原地更新.
3. **Keep at least one agent that cannot write to shared state.**仅读的验证器检测到输入,重新查找来源,并标记不一致.
   翻译: 中文**保留至少一个不能写入共享状态的 Agent。**由于它不能写入池,所以不能被池污染.

### 黑板先例 (海斯-罗思,1985年)

黑板模式比法师事务所代理人早了四十年. 哈伊斯-罗思 (1985,"控制的黑板架构") 描述了观察全球黑板的专业知识来源,贡献部分解决方案,并触发其他来源. 2026年黑板 (CA-MCP,矩阵) 与知识来源和部分解决方案的JSON片一样,具有LLM代理. 旧文献记录了写作争端,机会主义控制和一致性的解决方案,

> 黑板模式比LLM代理早已四十年.Hayes-Roth (1985,"一个黑板架构控制") 描述了观察全局黑板的贡献部分解决方案并触发其他来源专业知识源.

听力测试II的教训 (70年代语音识别黑板):机会主义控制 让任何知识来源触发当其触发条件匹配时产生突出解决问题的产品.现代代理系统,硬码工作流图失去了这一点.黑板的灵活性是其核心创新.

> 听说-II(1970年代语音识别黑板) 的教训:机会控制让任何知识源在其触发条件匹配时触发产生涌现的问题解决――硬编码工作流图的现代代理系统失去了这一点――黑板的灵活性是其核心创新――

### 无法写的验证器

最有效的减轻是仅可读的验证器.

> 最重要的缓解措施是仅阅读证书.

## 关键词 快速查找表

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Message pool / 消息池 | "Shared chat history" / "共享聊天历史" | Append-only log that every agent reads. Full transparency, poor scaling. / 每个 Agent 读取的仅追加日志。完全透明，扩展性差。 |
| Blackboard / 黑板 | "Shared workspace" / "共享工作区" | Topic-keyed pub/sub. Agents subscribe to relevant topics. Scales farther. / 基于主题的发布/订阅。Agent 订阅相关主题。扩展性更好。 |
| Provenance / 来源追溯 | "Who wrote what" / "谁写了什么" | Metadata on each write: writer, timestamp, prompt, sources. / 每次写入的元数据：写入者、时间戳、提示、来源。 |
| Memory poisoning / 内存污染 | "Hallucinations spreading" / "幻觉传播" | One agent's error enters shared state, downstream agents adopt it as fact. / 一个 Agent 的错误进入共享状态，下游 Agent 将其作为事实采纳。 |
| Append-only / 仅追加 | "No in-place updates" / "无原地更新" | Corrections are new entries that supersede. Preserves audit trail. / 修正项是取代旧条目的新条目。保留审计跟踪。 |
| Unwritable verifier / 不可写验证者 | "Independent auditor" / "独立审计者" | Read-only agent that re-fetches sources and flags inconsistencies. / 重新获取来源并标记不一致的只读 Agent。 |
| Projection / 投影 | "Scoped view" / "范围视图" | Per-agent view computed from global state. LangGraph reducers are the canonical case. / 从全局状态计算的每个 Agent 视图。LangGraph 归约器是典型实现。 |
| Knowledge Source / 知识源 | "Specialist agent" / "专家 Agent" | Hayes-Roth's 1985 term for a blackboard participant. / Hayes-Roth 1985 年对黑板参与者的称呼。 |

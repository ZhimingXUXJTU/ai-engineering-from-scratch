## 概念的核心概念

### 阶段1:监督的细调 (SFT)

收集即时响应对,响应是一个有善意的人会写的. Ouyang等人使用标签器和OpenAI API的13k提示.通过标准的跨缩损失,对此数据进行细节调整.

> 收集提示-响应对,其中响应是善意的标志者会写的内容――Ouyang等使用来自标志者和OpenAI API的13k提示词――使用标准交叉损失在这个数据微调基础模型――

现在,模型现在回答问题,而不是继续问题. 它没有给你什么:任何信号,即评级者喜欢多个答案是可行的.

> SFT给你:模型现在回答问题而不是继续补充它们.

> **【中文解读】**通过使用Bradley-Terry成成偏好损失L_RM = -log sigmoid(r(x,y_w) - r(x,y_l)) 在标注者排列中的补充对上训练奖励模型.RM通常从SFT模型开始并替换LM为标标题头,6B就足以指导175B模型.

### 第二阶段:奖励模式 (RM)

对于每一个提示,从SFT模型中样本K完成.一个标签符排名它们.训练一个奖励模型,该模型将任何提示响应对进行分数,以便,对于`y_w`现在,我觉得我更喜欢`y_l`其他:

> 对于每一个提示,从SFT 模型采样 K 个补充全.标记者对它们排序.`y_w`优于`y_l`的配对:

```
L_RM = -log sigmoid(r(x, y_w) - r(x, y_l))
```

这就是布拉德利-特里对偏好损失.RM通常从SFT模型开始,LM头被 Skalar头取代.

> 这是布拉德利-特里 成对偏好损失.RM通常从SFT模型初始化,语言模型头换为标量头.

奖励模型很小:6B足够用于175BInstructGPT.它们也很脆弱.

> 奖励模型很小:6B 就足以指导175B的指导GPT──但它们也很脆弱论文第5节主要讨论了小规模出现的奖励黑客行为──

> **【拓展：PPO 阶段 → RLHF 的核心工程】**阶段的目标函数J(pi) =E[r(x,y) ] - beta * KL(pi 于 pi_SFT) 最大化奖励同时保持接近SFT的策略──KL系数β是最重要的RLHF 超参数太低导致奖励黑客,太高则SFT 上没有改进──没有 KL 项,优化器发现的是RM从未见过的对抗样本分数高不是因为人类真正偏好,而是因为RM从未评估过这些输入──

### 阶段3:PPO与KL罚款

定义目标:

```
J(pi) = E_{x~D, y~pi(.|x)} [ r(x, y) ] - beta * KL(pi(.|x) || pi_SFT(.|x))
```

通过PPO最大化.KL术语保持.`pi`没有它,优化器会找到对立的例子 弦在RM下得分高,因为RM从来没有看到它们,而不是因为人类实际上更喜欢它们.

> 用PPO最大化.`pi`没有它,优化器会在RM下找到高分分的反抗样本字符串,因为RM从未见过它们,而不是人类真正的偏好.

基因系数`beta`太低:奖励黑客.太高:没有改善.

> 号`beta`太低:奖励黑客――太高:相比SFT 没有改进――

> **【中文解读】**对齐税:RLHF 后模型在人类偏好上更好,但在标准基准上退步.SQuAD,HellaSwag,DROP) 上退步.Ouyang等称之为"对齐税"并使用PPO-ptx修复将预训练梯度混入RL目标,使模型不忘记从未获得奖励的下游任务.

### 调整税

欧阳等人称之为"配合税",并用PPO-ptx来解决这一问题:将预训练梯度混合到RL目标中,使模型不会忘记如何完成下游任务,它从未获得奖励.

> 后,模型在人类偏好上更好,但在标准基准上退步.

```
J_ptx(pi) = J(pi) + gamma * E_{x~D_pretrain} [ log pi(x) ]
```

博是个标准的平台,而人类,深思维和Meta都使用了一些变体.

> 们都使用了一些变体.

> **【拓展：1.3B vs 175B → 对齐独立于能力】**1.3B 指示GPT 在标志者偏好上超过70%的时间胜过 175B GPT-3──在生产流量隐藏测试提示上的差距更大──两个关键点: 1) 对齐与能力不同轴175B 有更多能力, 1.3B 有更多对齐,标志者偏好对齐; 2) 能力下限由基础模型设定你不能RLHF 一个基础模型使它知道它从未见过的事实.

## 关键词 关键词

| Term | What people say | What it actually means |
| 术语 | 人们怎么说 | 实际含义 |
|------|-----------------|------------------------|
| SFT | "instruction tuning" / "指令微调" | Stage 1: cross-entropy fine-tune on prompt-response pairs / 阶段 1：在提示-响应对上交叉熵微调 |
| Reward model | "the RM" / "奖励模型" | Scalar regressor over (prompt, response) trained with Bradley-Terry on pairwise labels / 用 Bradley-Terry 在成对标签上训练的标量回归器 |
| Bradley-Terry | "pairwise preference loss" / "成对偏好损失" | -log sigmoid(r_w - r_l); reduces pairwise ranking to binary classification / 将成对排序简化为二分类 |
| KL penalty | "the regularizer" / "正则化器" | `beta * KL(pi \|\| pi_SFT)` — keeps the RL policy near the SFT anchor / 保持 RL 策略接近 SFT 锚点 |
| PPO-ptx | "PPO with pretraining mix" / "带预训练混合的 PPO" | Adds a fraction of pre-training log-likelihood to the PPO objective to offset the alignment tax / 将部分预训练对数似然加入 PPO 目标以抵消对齐税 |
| Alignment tax | "the RLHF regression" / "RLHF 退步" | Post-RLHF drop on standard benchmarks that RLHF did not target / RLHF 后在未针对的标准基准上的性能下降 |
| Labeler preference | "the ground truth" / "地面真实" | Sample of human rankings; the RM is a statistical proxy for this, not for "human values" / 人类排序的样本；RM 是其统计代理，而非"人类价值观" |

## अवधारणा का मूल अवधारणा

> **【中文解读】**इस भाग में मूल अवधारणाओं और सिद्धांतों की आधारभूत जानकारी दी गई है।

**Dialogue state.**(स्लॉट, मूल्य) जोड़े का एक सेट जो प्रत्येक मोड़ पर उपयोगकर्ता के लक्ष्य के बारे में सिस्टम को क्या पता है, उसे कैप्चर करता है। उदाहरणः {खाद्यः इतालवी, कीमतः मध्यम, क्षेत्रः उत्तर}.

> **对话状态。**प्रत्येक दौर में एक समूह (槽位, 值) के लिए, capturé system对用户目标的理解──例如:{खाद्यः इतालवी, कीमतः मध्यम, क्षेत्र: उत्तर}──

**State update.**प्रत्येक मोड़ पर, नए उपयोगकर्ता बयान के आधार पर स्थिति को अपडेट करें। तीन ऑपरेशनः सेट, अपडेट, हटाएं।

> **状态更新。**प्रत्येक दौर के वार्तालाप के आधार पर नए उपयोगकर्ता वार्तालाप अपडेट स्टेटस.

**Belief state.**संभावित स्लॉट मानों पर संभावना वितरण। उपयोगी जब उपयोगकर्ता अस्पष्ट है ("एक रेस्तरां" → रसोई = कोई नहीं, लेकिन विश्वास इतालवी = 0.3, चीनी = 0.2, ...) ।

> **信念状态。**संभवत स्थान मूल्य का अनुमानित वितरण──当用户模糊时有用量("一家餐厅" → रसोई=नहीं, लेकिन विश्वास इंगित करता है इतालवी=0.3、 चीनी=0.2、......)

### चरण 1: स्लॉट-मूल्य राज्य ट्रैकर

```python
class DialogueStateTracker:
    def __init__(self, slots):
        self.state = {slot: None for slot in slots}
        self.history = []

    def update(self, slot_values):
        for slot, value in slot_values.items():
            if slot in self.state:
                self.state[slot] = value
        self.history.append(dict(self.state))

    def get_missing_slots(self):
        return [s for s, v in self.state.items() if v is None]

    def is_complete(self):
        return all(v is not None for v in self.state.values())


tracker = DialogueStateTracker(["cuisine", "price", "area", "party_size"])
tracker.update({"cuisine": "Italian", "area": "north"})
print(tracker.get_missing_slots())  # ['price', 'party_size']
print(tracker.is_complete())  # False
```

## इसे फ्रेमवर्क के साथ लागू करें

> **【中文解读】**इस खंड में इस बात पर ध्यान दिया गया है कि मॉडल को उपयोग के लिए कैसे तैनात किया जाए।

- **Rule-based DST.**स्लॉट भरने के साथ regex + इकाई निष्कर्षण. तेजी से, पूर्वानुमानित. / 基于规则的DST──正则+实体提取──快速、可预测──
- **Neural DST.**मल्टीवोज़ या इसी तरह के डेटासेट पर ट्रेन. बेहतर सामान्यीकरण. / 神经 DST──在 मल्टीवोज़ 上训练──更好泛化──
- **LLM-based DST.**एलएलएम को राज्य अपडेट निकालने के लिए प्रेरित करें। लचीला, महंगा। / 基于LLM के DST──灵活──昂贵──
- **Hybrid.**निकासी के लिए एलएलएम + सत्यापन के लिए नियम आधारित। उत्पादन सिफारिश. / 混合──LLM 提取 + 规则验证──生产推──

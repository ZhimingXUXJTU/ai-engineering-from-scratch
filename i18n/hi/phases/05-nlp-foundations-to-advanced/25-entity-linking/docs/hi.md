## समस्या  समस्या परिचय

इकाई लिंकिंग (EL) ज्ञान आधार (विकिडेटा, विकिपीडिया, जियोनेम्स) में एक अद्वितीय प्रविष्टि के लिए प्रत्येक उल्लेख को हल करता है। दो चरणों की पाइपलाइनः उम्मीदवार पीढ़ी (संभावित मैचों को ढूंढें) और असंगति (सही चुनें) ।

> 实体链接(EL) प्रत्येक指称解析为知识库(विकिडेटा、विकिपीडिया、GeoNames) में एकमात्र条目──两步流水线:候选生成(找到可能的匹配) 和消歧(选择正确的) 👇

> **【中文解读】**इस खंड में उठाया गया प्रश्न यह हैः इस तकनीक को वास्तविक निर्माण में सही ढंग से कैसे समझा जाए और लागू किया जाए।

## अवधारणा का मूल अवधारणा

> **【中文解读】**इस भाग में मूल अवधारणाओं और सिद्धांतों की आधारभूत जानकारी दी गई है।

**Candidate generation.**"जॉर्डन" को देखते हुए, कौन सी KB प्रविष्टियाँ मेल खाती हैं? स्ट्रिंग मिलान, पुनर्निर्देशन संकल्प और लोकप्रियता पूर्वानुमान का उपयोग करें। आमतौर पर शीर्ष 10-50 उम्मीदवारों को पुनर्प्राप्त करें।

> **候选生成。**给定 "जॉर्डन", कौन से ज्ञान库条目匹配?

**Disambiguation.**संदर्भ समानता के अनुसार उम्मीदवारों को रैंक करें। गति के लिए द्वि-संकेतक, सटीकता के लिए क्रॉस-संकेतक। संदर्भ = आसपास का पाठ + KB से इकाई विवरण।

> **消歧。**按上下文相似度排名候选──双编码器用于速度,交叉编码器用于准确率──上下文 = 周围文本 + 知识库中的实体描述──

```python
def entity_link(mention, context, kb_lookup, embed_model):
    candidates = kb_lookup.get(mention.lower(), [])
    if not candidates:
        return None
    ctx_emb = embed_model.encode([context])
    scores = []
    for cand in candidates:
        cand_emb = embed_model.encode([cand["description"]])
        scores.append((cand, float(np.dot(ctx_emb[0], cand_emb[0]))))
    return max(scores, key=lambda x: x[1])[0]
```

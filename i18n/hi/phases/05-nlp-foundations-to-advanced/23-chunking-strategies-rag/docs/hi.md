## अवधारणा का मूल अवधारणा

> **【中文解读】**इस भाग में मूल अवधारणाओं और सिद्धांतों के आधार पर चर्चा की गई है। इन अवधारणाओं को प्राप्त करना बाद में प्राप्त होने की आवश्यकता है।

**Fixed-size chunking.**N-token ब्लॉकों में विभाजित पाठ वैकल्पिक ओवरलैप के साथ. सरल, तेज, आश्चर्यजनक रूप से प्रभावी. अधिकांश उत्पादन RAG प्रणालियों में डिफ़ॉल्ट.

> **固定大小分块。**इसे N टोकन के ब्लॉक में विभाजित करना, चयन योग्य ओवरले करना।

**Sentence-level chunking.**वाक्य सीमाओं पर विभाजित करें. प्रत्येक टुकड़ा = एक या अधिक वाक्य। FAQ और लघु उत्तर प्राप्त करने के लिए अच्छा है।

> **句子级分块。**में句子边界分割── प्रत्येक ब्लॉक = एक या अधिक वाक्य── अनुकूल FAQ 和短答案检查──

**Semantic chunking.**वाक्य एम्बेड करें, समान एम्बेड के साथ लगातार वाक्य को टुकड़ों में समूहित करें। कथा पाठ पर बेहतर, गणना में धीमा।

> **语义分块。**嵌入句子, 嵌入 करेंगे समान连续句子分组为块── बेहतर, गणना更慢──

**Recursive character chunking.**अनुच्छेद के अनुसार विभाजित, फिर वाक्य के अनुसार, फिर वर्ण के अनुसार।

> **递归字符分块。**按段落分割,然后按句子,然后按字符──长链的默认── अच्छा通用启发式──

### चरण 1: ओवरलैप के साथ निश्चित आकार का टुकड़ा

```python
def fixed_chunk(text, chunk_size=100, overlap=20):
    tokens = text.split()
    chunks = []
    for i in range(0, len(tokens), chunk_size - overlap):
        chunks.append(" ".join(tokens[i:i + chunk_size]))
    return chunks
```

### चरण 2: अर्थिक टुकड़ा

```python
from sentence_transformers import SentenceTransformer
import numpy as np

def semantic_chunk(text, model_name="sentence-transformers/all-MiniLM-L6-v2", threshold=0.5):
    model = SentenceTransformer(model_name)
    sentences = text.split(". ")
    embeddings = model.encode(sentences, normalize_embeddings=True)
    chunks = [sentences[0]]
    for i in range(1, len(sentences)):
        sim = np.dot(embeddings[i], embeddings[i-1])
        if sim < threshold:
            chunks.append(sentences[i])
        else:
            chunks[-1] += ". " + sentences[i]
    return chunks
```

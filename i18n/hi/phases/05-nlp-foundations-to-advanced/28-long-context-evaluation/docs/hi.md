## अवधारणा का मूल अवधारणा

> **【中文解读】**इस भाग में मूल अवधारणाओं और सिद्धांतों की आधारभूत जानकारी दी गई है।

**NIAH (Needle in a Haystack).**विभिन्न स्थानों पर एक लंबे दस्तावेज़ में एक विशिष्ट तथ्य डालें। मॉडल से इसे निकालने के लिए कहें। उपायः क्या मॉडल Y-टोनन сенаस्टैक में गहराई X पर एक सुई पा सकता है?

> **NIAH（大海捞针）。**मॉडल जांच करेंः मॉडल Y टोकन के सूखा घास के ढेर में गहराई X में सुई पा सकता है?

**RULER.**बहु-नाल, चर-दूरी और संश्लेषण कार्यों के साथ NIAH का विस्तार करता है। अधिक व्यापक।

> **RULER。**扩展 NIAH 添加多针、可变距离和聚合任务──更全面──

**LongBench.**वास्तविक दुनिया में दीर्घ संदर्भ कार्यः सारांश, क्यूए, पुनर्प्राप्ति, कोड। सिंथेटिक बेंचमार्क से अधिक प्रतिनिधि।

```python
def needle_in_haystack(model, context_length, needle, needle_position):
    """Insert needle at position in a long document and test retrieval."""
    haystack = generate_irrelevant_text(context_length)
    full_text = haystack[:needle_position] + f"\n{needle}\n" + haystack[needle_position:]
    question = f"What is the secret fact hidden in the text?"
    response = model(full_text + "\n\n" + question)
    return needle.lower() in response.lower()
```

## समस्या  समस्या परिचय

संदर्भ विंडो मेमोरी को हल करने के लिए लगती है। वे नहीं करते. तीन विफलता मोड उत्पादन में दोहराया जाता हैः

> उपरोक्त विंडो में स्मृति समस्या का समाधान करने में सक्षम प्रतीत होता है, लेकिन वास्तव में यह संभव नहीं है।

1. **Overflow.**कई बार बातचीत, लंबे दस्तावेज, या उपकरण-कल्लिंग भारी पटरियों खिड़की पार. कटऑफ के बाद सब कुछ गायब हो गया है.
   中文翻译:**溢出。**अनेक दौर वार्ता, दीर्घलेख या उपकरण का प्रयोग गहन का मार्ग पार खिड़की सीमाएँ।
2. **Dilution.**यहां तक कि खिड़की के अंदर भी, अप्रासंगिक संदर्भ भरने से ध्यान को महत्वपूर्ण चीजों पर पतला कर दिया जाता है। सीमांत मॉडल अभी भी लंबे इनपुट पर गिरावट आते हैं।
   中文翻译:**稀释。**यहां तक कि खिड़की के अंदर भी, अपूर्ण उपरोक्त में महत्वपूर्ण सामग्री पर ध्यान देने की कमी है।
3. **Persistence.**एक नया सत्र एक खाली खिड़की के साथ शुरू होता है. बाहरी स्मृति के बिना एजेंटों को नहीं कह सकते "याद रखें जब आप मुझसे पूछा है ..." सत्रों के बीच.
   中文翻译:**持久化。**नई बैठक खाली खिड़की से शुरू हुई। कोई बाहरी स्मृति नहीं है। एजेंट ने कहा कि "याद है कि आप मुझे"...

> **【中文解读】**उपरोक्त विंडो में स्मरण की समस्या को हल करने की क्षमता प्रतीत होती है, लेकिन वास्तव में यह संभव नहीं है। उत्पादन वातावरण में तीन असफल मोड हैंः 1) 溢出多轮对话或长文档跨越窗口限制,截断以外 सब कुछ खो गया है; 2) 稀释 विंडो में भरा हुआ अप्रासंगिक उपरोक्त में ध्यान केंद्रित किया गया है; 3) 持久化新会话从空窗开始,Agent 无法跨会话记忆──

मेम0 के 2025 के पेपर में मापा गया है कि 128k विंडो बेसलाइन अभी भी लंबे क्षितिज के तथ्यों को याद करती है जो बाहरी मेमोरी के साथ 4k विंडो एजेंट पकड़ता है।

> अधिक बड़ी खिड़की मदद करता है लेकिन इस समस्या को हल नहीं कर सकता है।

> **【拓展：MemGPT → 现代 Agent 记忆系统】**MemGPT (Packer et al., 2023) ने ऑपरेटिंग सिस्टम के लिए वर्चुअल内存 के लिए निम्नलिखित प्रकार के प्रबंधन का वर्णन किया हैः मुख्य पर निम्न = RAM, बाहरी भंडारण = डिस्क, स्मृति उपकरण = पृष्ठ परिवर्तन में परिवर्तन आउटपुट। यह 2026 के सभी स्मृति प्रणाली का मूल मॉडल है।

>  **【前置】**必須先掌握:चरण 14·01(एजेंट लूप) MemGPT का स्मरण उपकरण है साधारण उपकरण调用扩展;चरण 14·06(Tool Use)  स्मरण संचालन उपकरण के माध्यम से प्राप्त करना──还需要操作系统基础知识 यदि आप नहीं जानते कि "虚拟内存""页面错误" क्या है, तो पहले ऑपरेशन सिस्टम को पूरक करें, अन्यथा类比看不懂──

## अवधारणा का मूल अवधारणा

### ओएस एनालॉग

MemGPT (Packer et al., arXiv:2310.08560, v2 Feb 2024) परिवेश प्रबंधन को ऑपरेटिंग सिस्टम की आभासी स्मृति में मानचित्रित करता हैः

> पैकर 等人(arXiv:2310.08560, v2 2024 साल 2 月) will on下文管理映射到操作系统虚拟内存:

| OS concept | MemGPT concept | 2026 production analog |
|------------|---------------|------------------------|
| OS 概念 | MemGPT 概念 | 2026 生产环境类比 |
| RAM | main context (prompt) | Anthropic/OpenAI context window / 主上下文（提示） |
| Disk | external context | vector DB, KV, graph store / 外部上下文（向量数据库、KV、图存储） |
| Page fault | memory tool call | `memory.search`, `memory.read`, `memory.write` / 记忆工具调用 |
| OS kernel | agent control loop | ReAct loop with memory tools / 带记忆工具的 ReAct 循环 |

एजेंट एक सामान्य ReAct लूप चलाता है। एक अतिरिक्त उपकरण वर्ग उसे मुख्य संदर्भ में और बाहर पेज डेटा करने की अनुमति देता है।

>  **【类比】**MemGPT 像你电脑的内存管理:RAM(主上下文) केवल 8GB है लेकिन फ़ोटोशॉप + ब्राउज़र + आईडीई चलाना है; ऑपरेटिंग सिस्टम पृष्ठ के माध्यम से पृष्ठ में परिवर्तन में परिवर्तन में बाहर आना है (पृष्ठ में परिवर्तन) आपको "अनुभूति" करने के लिए है अंतहीन内存──MemGPT 让代理也这样做主上下文塞不下时,代理自调用 `archival_memory_search`                                                                                                                                                                                                                                                              `core_memory_replace`इसे "बदला" देना।

> एजेंट 运行普通的 ReAct 循环―― अतिरिक्त प्रकार के उपकरण जिससे यह मुख्य उप-पृष्ठ और बाहरी भंडारण के बीच डेटा के आदान-प्रदान में सक्षम हो सके―

> **【中文解读】**MemGPT 将上下文管理映射到操作系统虚拟内存:RAM=主上下文(当前提示),磁盘=外部上下文(向量数据库/KV/图存储),页面错误=记忆工具调用(`memory.search`/`memory.read`/`memory.write`),OS内核=एजेंट 控制循环──एजेंट 运行普通的 ReAct 循环, अतिरिक्त वृद्धि एक प्रकार का उपकरण है जो मुख्य पृष्ठ पर नीचे और बाहरी भंडारण के बीच डेटा के आदान-प्रदान में उपयोग किया जाता है──

### विराम पैटर्न

MemGPT मेमोरी-अवरोध के रूप में पेश करता हैः वार्तालाप के बीच में एजेंट एक मेमोरी टूल को कॉल कर सकता है, रनटाइम इसे निष्पादित करता है, और परिणाम एक नए अवलोकन के रूप में अगले सहायक वक्र में स्प्लिक्स करता है।`read()`syscall जो प्रक्रिया को अवरुद्ध करता है, बाइट्स वापस करता है, और प्रक्रिया जारी है।

> MemGPT ने स्मृति की स्थापना कीः वार्तालाप में एजेंट स्मृति उपकरण को संचालित कर सकता है, इसे निष्पादित करता है, परिणाम के रूप में एक नया निरीक्षण अगली सहायक दौर में शामिल किया गया है।`read()`系统调用阻塞进程、返回字节、进程继续──

कैनोनिक मेमोरी टूल सतहः

> 标准记忆工具接口:

- `core_memory_append(section, text)` प्रॉम्प्ट के एक निरंतर अनुभाग में लिखें।
  中文翻译:`core_memory_append(section, text)`写入提示的持久化分区──
- `core_memory_replace(section, old, new)` एक निरंतर अनुभाग को संपादित करें।
  中文翻译:`core_memory_replace(section, old, new)` 编辑持久化分区──
- `archival_memory_insert(text)` खोज योग्य बाहरी स्टोर पर लिखें।
  中文翻译:`archival_memory_insert(text)` write in searchable of external storage──

  中文翻译:`archival_memory_search(query, top_k)` बाहरी भंडार से चेक-आउट

  中文翻译:`conversation_search(query)`扫描过去的轮次──

### जहां यह पैटर्न गलत हो जाता है

> ️ **【易错点】**MemGPT 新手最容易忽略"记忆投毒": बाहरी वेबपृष्ठ 用户消息直接 `archival_memory_insert` बाहरी भंडारण में**后果**: हमलावर ने इस लेख को याद करने के लिए आदेश दिया है।**一行修复**: सभी अभिलेखागार में प्रवेश करने वाली बाहरी सामग्री को पहले सुरक्षित करना होगा।

- **Memory rot.**लेखन पढ़ने की तुलना में तेजी से जमा होता है; पुनर्प्राप्ति पुराने तथ्यों में डूब जाता है। फिक्सः आवधिक समेकन (लेटा नींद समय), स्पष्ट अवैधता (मेम0 संघर्ष डिटेक्टर) ।
  中文翻译:**记忆腐化。**写入积累速度快于读取;检索被过时事实淹没──修复:定期合并(Leta sleep-time)、显式失效(Mem0 冲突检测器)──
- **Memory poisoning.**बाहरी मेमोरी में पाठ निकाला जाता है. यदि हमलावर नियंत्रित सामग्री मेमोरी नोट में आती है, तो एजेंट इसे अगले सत्र में फिर से प्रवेश करता है। यह Greshake et al. (Lection 27) समय के साथ फिर से हमला किया गया है।
  中文翻译:**记忆投毒。**बाहरी स्मृति खोजे गए पाठों में है। यदि हमलावर नियंत्रण की सामग्री स्मृति नोट में प्रवेश करती है, तो एजेंट इसे अगले सत्र में पुनः कैप्चर करेगा।
- **Citation loss.**एजेंट याद करता है "उपयोगकर्ता ने मुझे एक्स भेजने के लिए कहा" लेकिन कौन सा मोड़ नहीं बता सकता है। हर संग्रह लेखन के साथ स्रोत संदर्भ (सत्र आईडी, मोड़ आईडी) स्टोर करें।
  中文翻译:**引用丢失。**एजेंट याद" उपयोगकर्ता मुझे X" जारी करने के लिए अनुमति देता है लेकिन किसी भी दौर का उल्लेख नहीं कर सकता है।

### एजेंट स्मृति का आकार

पृष्ठिंग क्षमता को हल करता है। यह यह तय नहीं करता है कि क्या संग्रहीत किया जाना है। चार मेमोरी प्रकार उत्पादन प्रणालियों में दोहराए जाते हैं, प्रत्येक एक अलग सवाल का जवाब देता हैः

- **Working memory** अब क्या मायने रखता है? संदर्भ स्तरः वर्तमान कार्य, हाल ही में बारी, pinned कोर अनुभाग। प्रम्प्ट स्वयं।
- **Episodic memory** क्या हुआ? पिछले मोड़ और पटरियों, सत्र और मोड़ संदर्भ के साथ संग्रहीत, मांग पर पुनः खेला जा सकता है।
- **Semantic memory** क्या सच है? उपयोगकर्ता, डोमेन, दुनिया के बारे में तथ्य, अद्यतन और बदलते समय दोहराया जाता है।
- **Procedural memory**मैंने ऐसी आदतें, वरीयताएं और नियम सीखे हैं जो याद करने के बजाय भविष्य के व्यवहार को निर्देशित करते हैं।

ओपन सोर्स कार्यान्वयन विभिन्न हमले के बिंदुओं को चुनते हैंः

| Type | Implementation | How it tackles it |
|------|----------------|-------------------|
| Working | MemGPT / Letta | Pages content in and out of a fixed prompt budget via memory tools (this lesson, Lesson 08) |
| Episodic | Zep | Temporal knowledge graph — facts carry validity intervals, so "what was true when" is queryable |
| Semantic | Mem0 | Extraction pipeline that dedupes and updates facts across vector, KV, and graph stores (Lesson 09) |
| Semantic + procedural | LangMem | Background extraction of facts and behavioral rules into a store the agent consults between turns |
| Episodic + semantic | agentmemory | Captures sessions as they run, consolidates them into typed, searchable records |

## कीवर्ड्स  शब्द खोज तालिका

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| 术语 | 通俗说法 | 实际含义 |
| Virtual context | "Unlimited memory" / "无限记忆" | Main (prompt) + external (searchable) tiers with page in/out / 主（提示）+ 外部（可搜索）两层，带页面换入/换出 |
| Main context | "Working memory" / "工作记忆" | The prompt — fixed-size, always visible / 提示——固定大小，始终可见 |
| Archival memory | "Long-term store" / "长期存储" | External searchable persistence, retrieved on demand / 外部可搜索持久化，按需检索 |
| Core memory | "Persistent prompt section" / "持久化提示分区" | Named sections pinned inside the main context / 固定在主上下文内的命名分区 |
| Memory tool | "Memory API" / "记忆 API" | Tool call the agent issues to read/write external memory / Agent 发出的读/写外部记忆的工具调用 |
| Interrupt | "Memory page fault" / "记忆页面错误" | Agent pauses, runtime fetches, result splices into next turn / Agent 暂停、运行时获取、结果拼接到下一轮 |
| Memory rot | "Stale facts" / "过时事实" | Old writes drown retrieval; fix with consolidation / 旧写入淹没检索；用合并修复 |
| Memory poisoning | "Injected persistent note" / "注入的持久化笔记" | Attacker content stored as memory, re-ingested on recall / 攻击者内容存储为记忆，在回忆时重新摄取 |

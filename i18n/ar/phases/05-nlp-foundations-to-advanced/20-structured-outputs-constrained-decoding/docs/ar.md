> في عام 2026، هناك ثلاثة مستويات.

1. **Prompting.**أسأل بشكل لطيف. "رجع فقط موضوع JSON". يعمل ~ 85-95% من الوقت. يفشل في الحافة الحالات، المخرجات الطويلة، وإدخالات معارضة. / **提示。**الطلب جيد. "رجع فقط إلى JSON للموضوعات". حوالي 85-95% من الوقت فعال.

3. **Tool/function calling.**إنتاج مهيكلي عبر واجهة الاتصال الأداة الأصلية للنموذج. يقوم النموذج بإرسال كائن JSON مباشرة ، وليس كنص. أفضل تأخر ، أفضل موثوقية ، ولكن محدد للنموذج. / **工具/函数调用。**通过模型原生工具调用接口的结构化输出──最佳延迟,最佳可靠性,但模型特定──

## المفهوم الأساسي

> **【中文解读】**هذا المقطع يعرض المفاهيم والنظريات الأساسية. فهم هذه المفاهيم هو شرط لتحقيق التنفيذ التالي، وكذلك النقاط المعرفة في المقابلة والممارسة التجريبية.

**Logit masking.**في كل خطوة من مراحل التوليد، ينتج النموذج توزيع الاحتمالات على المفردات. يقوم التشريح المحدود بحساب مجموعة من الرموز التالية المفعلة (نظراً للخطط وما تم إنشاؤه حتى الآن) ويقوم بتعيين جميع اللوجات الأخرى إلى -inf قبل softmax. يمكن لنموذج اختيار فقط من الرموز المفعلة.

> **Logit 屏蔽。**في كل خطوة إنتاج، النموذج على جدول الكلمات تنتج توزيع احتمالاتها.

**JSON schema constraints.**بالنسبة إلى إصدار JSON ، فإن القيود تفرض: تشبث الحوافز المفتوحة مع الحوافز المغلقة ، يتم اقتباس الأزرار حوافز ، وتتطابق القيم مع أنواعها المعلنة ، وتحتوى الحقول المطلوبة ، لا توجد حقول إضافية خارج النمط. هذه قيود قواعد غير سياقية ، يتم تحسيبها بشكل تدريجي.

> **JSON 模式约束。**对于 JSON 输出,约束强制:开闭括号匹配、键是带引号字符串、值匹配声明类型、必填字段存在、无模式外额外字段──这是一个上下文无关语法约束,增量计算──

> **【拓展：大语言模型的工程实践】**من GPT إلى ChatGPT، تمر NLP من "كل مهمة تدريب نموذج" إلى "نموذج حل جميع المهام" التحول النموذجية. في المشاريع العملية، تحتاج نشر LLM إلى النظر في إيقاع الاختيارات التوقيتية التأخير التكلفة والتحقق الأمني وغيرها من المشاكل.

### الخطوة 2: تأكيد مخطط JSON أثناء توليد

```python
import jsonschema

schema = {
    "type": "object",
    "properties": {
        "name": {"type": "string"},
        "age": {"type": "integer", "minimum": 0},
    },
    "required": ["name", "age"],
}

def validate_json_output(text, schema):
    try:
        data = json.loads(text)
        jsonschema.validate(data, schema)
        return True, data
    except (json.JSONDecodeError, jsonschema.ValidationError) as e:
        return False, str(e)
```

|------|-----------------|-----------------------|

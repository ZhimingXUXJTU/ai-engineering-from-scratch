## المفهوم الأساسي

> **【中文解读】**هذا المقطع يعرض الأساس النظري والفكرة الأساسية.

**Dialogue state.**مجموعة من أزواج (الفرصة، القيمة) التي تلتقط ما يعرفه النظام عن هدف المستخدم في كل جولة.

> **对话状态。**每轮对话中一组 (槽位, 值) 对,捕获系统对用户目标的理解──例如:{طبخ: الإيطالية, سعر: معتدل, منطقة: شمال}──

**State update.**في كل مرة، قم بتحديث الحالة بناءً على تصريح المستخدم الجديد. ثلاث عمليات: تعيين، تحديث، حذف.

> **状态更新。**كل دورة من المحادثات حسب حالة حديثة جديدة.

**Belief state.**توزيع الاحتمالات على قيم القمار المحتملة. مفيد عندما يكون المستخدم غامضًا ("مطعم" → مطعم = لا شيء ، ولكن الاعتقاد يظهر الإيطالي = 0.3 ، الصيني = 0.2 ، ...).

> **信念状态。**ربما تكون هذه المجموعة من المستخدمين المستخدمين في المجموعة المستخدمة.

### الخطوة الأولى: متابعة حالة القيمة السباقية

```python
class DialogueStateTracker:
    def __init__(self, slots):
        self.state = {slot: None for slot in slots}
        self.history = []

    def update(self, slot_values):
        for slot, value in slot_values.items():
            if slot in self.state:
                self.state[slot] = value
        self.history.append(dict(self.state))

    def get_missing_slots(self):
        return [s for s, v in self.state.items() if v is None]

    def is_complete(self):
        return all(v is not None for v in self.state.values())


tracker = DialogueStateTracker(["cuisine", "price", "area", "party_size"])
tracker.update({"cuisine": "Italian", "area": "north"})
print(tracker.get_missing_slots())  # ['price', 'party_size']
print(tracker.is_complete())  # False
```

## استخدمها في إطار التنفيذ

> **【中文解读】**هذا المادة يركز على كيفية نشر النموذج على المنتجات المتاحة.

- **Rule-based DST.**ملء فتحة مع إستخراج كيانات ريجكس + سريعة، يمكن التنبؤ بها. / 基于规则的DST──正则 + 实体提取──快速、可预测──
- **Neural DST.**تدريب على MultiWOZ أو مجموعة بيانات مماثلة. التعميم الأفضل. / 神经 DST──在 MultiWOZ 上训练──更好泛化──
- **LLM-based DST.**تحفيز ماجستير في العلوم لتسجيل تحديثات الدولة. مرنة، مكلفة.
- **Hybrid.**ماجستير في مجال الاستخراج + قاعدة على أساس التحقق. توصية الإنتاج. / 混合──LLM 提取 + 规则验证──生产推──

## شروط الرئيسية

| Term / 术语 | What it means / 含义 |
|------|-----------------------|
| Dialogue state（对话状态） | Current (slot, value) pairs. / 当前槽位-值对。 |
| Slot filling（槽位填充） | Extracting values for predefined slots. / 为预定义槽位提取值。 |
| Belief state（信念状态） | Probability distribution over slot values. / 槽位值的概率分布。 |

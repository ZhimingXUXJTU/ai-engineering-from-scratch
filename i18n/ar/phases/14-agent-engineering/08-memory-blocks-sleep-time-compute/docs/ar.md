   中文翻译:**记忆腐化。**写入积累――矛盾的事实保留――检索被过时内容淹没――

### حواجز الذاكرة

الكتلة هي قسم من نوعها، المستمر، قابل للتحرير من المستوى الأساسي. وصفت ورقة MemGPT الأصلية اثنين:

> 块是核心层的类型化,持久化,可编辑分区──原始 MemGPT论文定义了两个:

- **Human block** حقائق عن المستخدم (اسم، دور، تفضيلات، أهداف).
  中文翻译:**Human 块** حول واقع المستخدم (اسم،角色،偏好، هدف)
- **Persona block** مفهوم الشخص نفسه (هوية، نغمة، قيود).
  中文翻译:**Persona 块**أعمال العاملة (أعمال العاملة)

Letta يُعمّل إلى كتلة تعريفية تعسفية للمستخدم: a `Task`حظر الهدف الحالي،`Project`حظر للحقائق القائمة على الرمز،`Safety`كل بلاك لديه`id`،`label`،`value`،`limit`(قيمة الكترونية)`description`(حيث يعرف النموذج متى يحرره)

> Letta 泛化为任意用户定义块:用于当前目标的 `Task`块、用于代码库事实 `Project`块、用于硬约束的 `Safety`كل قطعة لها`id`.`label`.`value`.`limit`(خطاب على الحد)`description`(جعلي الموديل يعرف كيف يُعدّها)

يمكن تحرير الكتل عبر سطح الأداة:

> 块通过工具接口可编辑:

- `block_append(label, text)`
  中文翻译:`block_append(label, text)`向块追加文本。
- `block_replace(label, old, new)`
  中文翻译:`block_replace(label, old, new)`替换块中的文本──
- `block_read(label)`
  中文翻译:`block_read(label)`读取块内容──
- `block_summarize(label)` إضافة حجر قريب من حدته
  中文翻译:`block_summarize(label)` الضغط يقترب من الحد الأقصى

### حساب وقت النوم

إضافة 2025 Letta: تشغيل وكيل ثان في الخلفية، خارج المسار الحرج. وكلاء وقت النوم معالجة النصوص المحادثة والسياق القاعدة التعليمية، كتابة `learned_context`إلى كتلة مشتركة، وتوحيد أو إلغاء سجلات الأرشيف.

> 2025 Letta: في الخلفية تعمل وكيل ثان، لا يوجد طريق رئيسي على الدوام.`learned_context`写入共享块,并合并或使归档记录失效──

الخصائص التي تسقط:

> الخصائص المترتبة عليه:

- **No latency cost.**الردود الأساسية لا تنتظر عمليات الذاكرة.
  中文翻译:**无延迟成本。**主响应不等待记忆操作──
- **Stronger model allowed.**يمكن أن يكون وكيل وقت النوم نموذجًا أكثر تكلفة وبطء لأنه ليس مقيدًا على التأخير.
  中文翻译:**允许更强的模型。**الوكيل الراحة يمكن أن يكون أكثر تكلفة ‬أطول النموذج، لأنه لا يتأثر بالتأخير‬
- **Natural consolidation window.**إضافة، تلخيص، إلغاء الحقائق المتناقضة عندما لا ينتظر المستخدم.
  中文翻译:**天然的合并窗口。**في المستخدم لا ينتظر وقت إعادة الإجراءات المختلفة

الشكل يطابق كيف يعمل البشر: تقوم بالمهمة، تنام عليها، وتستقر الذاكرة طويلة الأجل خلال الليل.

>  **【类比】**حساب وقت النوم 像夜晚的清洁工:白天你(主代理) مشغول في الاستجابة للعملاء، المكاتب(主上下文)堆满今天的会议记录、文件、咖啡杯;晚晚清洁工(夜间清洁工)进来擦桌子、归档文件、把"明天要跟进的事"贴到便利贴上(写入人/任务块) ・・・第二天你来上班,看整洁待机面和清晰的办理清单──**关键**: التنظيف يمكن أن يبطئ قليلا ً 贵一点  باستخدام نموذج أقوى) ، لأن العملاء لا ينتظرون‬

### حيث يذهب هذا النمط خطأ

> ️ **【易错点】**"静默漂移" هو أخطاء أكثر خطورة في عملية التنفيذ في Letta: عميل وقت النوم في الخلفية قام بتغيير شخصية 块 (مثلاً "始终用中文回复"改成"中英文混用"), ولكن العميل الرئيسي لا يعرف.**后果**: يكتشف المستخدم أن سلوك العميل يتغير ولكنه لا يبحث عن سبب لإن يوميات الحوار تسجل فقط إصدار العميل الرئيسي.**一行修复**: كل مرة النوم 写入后版本化块 内容, و في المرحلة التالية من العميل الرئيسي

- **Block bloat.**لا نهاية لها`block_append`يصل إلى الحد السريع. قم بتشغيل مخطط مخطط قبل الكتابة التي تدفع فوق القبو.
  中文翻译:**块膨胀。**لا حدود`block_append` بسرعة الوصول إلى الحد الأعلى  قبل أن يكتشف الحد الأعلى 
- **Silent drift.**وكيل النوم يكتب مرة أخرى حجر و العامل الأساسي لا يلاحظ أبداً.
  中文翻译:**静默漂移。**العامل المُستلق يكتب كتبها مجدداً لكن العامل الرئيسي لم يلاحظها
- **Poisoned consolidation.**وكيل وقت النوم يعالج المحتوى الذي يمكن للمهاجم الوصول إليه في القلب. الدرس 27 ينطبق على سطح وقت النوم أيضا.
  中文翻译:**投毒合并。**休眠代理将攻击者可达的内容处理进核心. 第 27 课也适用于休眠接口.

> 🤔 **【困惑】**س: وكيل وقت النوم باستخدام نموذج أقوى لن يكون أكثر تكلفة؟ لماذا هو صرف المال بدلا من الحرق؟ ج: انظر الوقت الدرجة.**避开了关键路径的高价** العميل الرئيسي 必須使用流動 + 高優先,单价是批量的2-3倍──把"可以慢" العمل المجموعة تنتقل إلى وقت النوم,整体反而便宜──

2. تنفيذ تخفيض وقت النوم على الأرشيف: تسجيلين يحتويون على نص يتداخل بينهما على نحو 90% يتداخل مع واحد.

## شروط الرئيسية

| Term | What people say | What it actually means |
|------|-----------------|-----------------------|
| 术语 | 通俗说法 | 实际含义 |
| Memory block | "Editable prompt section" / "可编辑提示分区" | Typed, persistent, LLM-editable segment of core memory / 类型化、持久化、LLM 可编辑的核心记忆段 |
| Human block | "User memory" / "用户记忆" | Facts about the user, pinned in core / 关于用户的事实，固定在 core 中 |
| Persona block | "Agent identity" / "Agent 身份" | Self-concept, tone, constraints, pinned in core / 自我概念、语气、约束，固定在 core 中 |
| Sleep-time compute | "Async memory work" / "异步记忆工作" | Second agent doing consolidation off the critical path / 第二个 Agent 在关键路径之外做合并 |
| Core / Recall / Archival | "Tiers" / "层级" | Three-layer memory split: always-visible / conversation / external / 三层记忆拆分：始终可见 / 对话 / 外部 |
| Block limit | "Cap" / "上限" | Character limit per block; forces summarization / 每个块的字符限制；强制摘要 |
| Native reasoning | "Thinking channel" / "思考通道" | Provider-level reasoning output, not prompt-level `Thought:` / 提供商级推理输出，非提示级 `Thought:` |
| Learned context | "Sleep output" / "休眠输出" | Facts the sleep-time agent writes into shared blocks / 休眠 Agent 写入共享块的事实 |

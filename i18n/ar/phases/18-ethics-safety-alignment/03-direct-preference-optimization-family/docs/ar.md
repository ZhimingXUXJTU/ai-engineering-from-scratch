## المشكلة المشكلة المشكلة

هدف RLHF (الدرس 1):

> الـ (RLHF 目标) الدروس 1:

```
max_pi E_{x,y~pi} [ r(x, y) ] - beta * KL(pi || pi_ref)
```

لديه أداء أفقي معروف:

> هناك أفضل حل معروف:

```
pi*(y|x) = (1/Z(x)) * pi_ref(y|x) * exp(r(x, y) / beta)
```

لذا، يتم تعريف المكافأة ضمنياً عن طريق نسبة السياسة المثلى للمرجع:

> لذلك، يتم تعريف نسبة المكافآت من خلال أفضل استراتيجيات إلى استراتيجيات المرجعية على النحو التالي:

```
r(x, y) = beta * log(pi*(y|x) / pi_ref(y|x)) + beta * log Z(x)
```

استبدل هذا في احتمال تفضيل برادلي تيري و وظيفة القسم`Z(x)`إلغاء لأنه يعتمد فقط على`x`ما تبقى هو خسارة في ملامح السياسة وحدها لا حاجة إلى نموذج مكافأة. هذا هو DPO.

> و سوف نضع هذا في برادلي تيري`Z(x)`لأنّه يعتمد فقط`x`و抵消── الباقي هو خسرة وظيفة للاستراتيجية العادية لا حاجة إلى نموذج مكافأة── هذا هو DPO──

التجاعيد: يفترض الإستحداث أن الإيجابية يمكن الوصول إليها، وتتبع بيانات الاختيارات في التوزيع، وسياسة المرجعية هي المرسوم الحقيقي للطريقة. لا يوجد أي من هذه المعلومات صحيحة تماما. يصلح كل عضو في الأسرة افتراض مختلف انتهك.

> المشكلة تكمن في: إدخال فرضيات أفضل قدر ممكن، وتوزيع البيانات المفضلة، والإستراتيجية المرجعية هي حقيقية.

L_DPO = -log sigmoid(

  ترجمة باللغة الصينية: خسارة المحرك للخيار والرفض من احتمالات العدد نحو الاتجاه المعاكس.

> **【拓展：IPO → DPO 的边界控制】**أبو (بالإنجليزية: IPO) ((تأثيرات الهوية المثلى) باستخدام خيارات خريطة مثل (恒等) استبدال سجل-سمميد، تم تحديد الفجوة في الفجوة 1/(2*بيتا) 封顶.

### الاكتتاب (أزار وغيره، 2024)

تحسين تفضيل الهوية يحل محل السجل السجني بخطوط هوية على احتمال تفضيل. يصبح الخسارة خطأ مربع على هدف محدد:

> باستخدام خيارات التخزين المتحركة لتحويل المخططات إلى المخططات المتحركة، تم تحويل الفجوة إلى 1/(2*بيتا) 封顶.

```
L_IPO = (log(pi(y_w | x) / pi_ref(y_w | x)) - log(pi(y_l | x) / pi_ref(y_l | x)) - 1/(2 beta))^2
```

الحدود تحددها `1/(2 beta)`قوة الاختيار والفجوة بين المكافآت المضطربة متناسبة

> الحدود تم`1/(2 beta)`封顶──偏好强度和隐式奖励差距成正比──不会爆炸──

> **【拓展：KTO → 无配对数据训练】**كتو (Kahneman-Tversky Optimization) هو الابتكار الرئيسي للتخلي عن المزاد تماما من الهيكل، ويحتاج فقط إلى علامة واحدة على إصدار "مثالي" أو "غير مثالي". هذا توسع بشكل كبير نطاق البيانات المتاحة للتدريب.

### سمبو (منغ وزملاؤه، 2024)

تحسين التفضيلات البسيطة ينسجم إشارة التدريب مع التوليد. إزالة سياسة المرجعية بالكامل وتطبيع احتمالات التسجيل حسب الطول:

> سيمبو سوف تدرب الإشارات وتوليدها على التكامل.

```
L_SimPO = -log sigmoid(
  (beta / |y_w|) * log pi(y_w | x)
  - (beta / |y_l|) * log pi(y_l | x)
  - gamma
)
```

مع هامش `gamma`يزيل التطبيع على الطول الحافز على استغلال وضع فشل التمييز الطويل من DPO (طول `y_w`يعطي فجوة أكبر من خلال البناء).

> مع الحدود`gamma`تدريبات ثابتة: إعادة التأهيل إلى الطول أزيل تحفيز استخدام نمط DPO لتحديد المدى`y_w`تُنتج اختلافات أكبر في احتمالية النسب

## شروط رئيسية

| Term | What people say | What it actually means |
| 术语 | 人们怎么说 | 实际含义 |
|------|-----------------|------------------------|
| DPO | "RLHF without a reward model" / "没有奖励模型的 RLHF" | Loss derived from the closed-form RLHF optimum; policy parameters only / 从闭式 RLHF 最优解推导的损失；仅策略参数 |
| Implicit reward | "the log-ratio" / "对数比率" | `beta * log(pi(y\|x) / pi_ref(y\|x))` — the DPO-implied reward / DPO 隐含的奖励 |
| IPO | "bounded DPO" / "有界 DPO" | Replaces log-sigmoid with identity; implicit reward gap capped by `1/(2 beta)` / 用恒等映射替换 log-sigmoid；隐式奖励差距被 `1/(2 beta)` 封顶 |
| KTO | "unpaired DPO" / "非配对 DPO" | Prospect-theory utility over single labels with loss aversion / 带损失厌恶的单标签前景理论效用 |
| SimPO | "reference-free DPO" / "无参考 DPO" | Length-normalized log-likelihood + margin; no reference policy / 长度归一化对数似然 + 边际；无参考策略 |
| ORPO | "one-stage DPO" / "单阶段 DPO" | NLL + odds-ratio preference term; trains from base model in one pass / NLL + 胜率比偏好项；单阶段从基础模型训练 |
| BPO | "chosen-preserving DPO" / "保留选择的 DPO" | DPO plus a penalty for decreasing the chosen response's absolute log-prob / DPO 加上降低选择响应绝对对数概率的惩罚 |
| Degraded Chosen | "chosen goes down" / "选择概率下降" | DPO decreases chosen log-prob so long as rejected falls faster / DPO 降低选择对数概率只要拒绝下降更快 |
| DAA | "direct alignment algorithm" / "直接对齐算法" | Any preference-loss method that skips an explicit RM / 任何跳过显式 RM 的偏好损失方法 |

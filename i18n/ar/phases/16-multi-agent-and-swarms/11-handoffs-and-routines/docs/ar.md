## مشكلة إدخال مشكلة

كل إطار عمل متعدد الوكلاء يريد منك أن تتعلم DSL: العقد والحواف LangGraph، طاقم CrewAI ومهام، AutoGen GroupChat والمديرين. DSLs مجرد تجريدي حقيقي، لكنها تجعل الشيء يشعر أكثر ثقلًا مما يحتاج إلى أن يكون.

> كل عدة وكيل  إطار يريد أن تجعلك تتعلمها DSL: قطاعات وجانب LongGraph  فريق و مهام CrewAI  مجموعة Chat و مدير آتوجين  DSL هي مجرد مجرد، ولكن أنها تجعل الأمور تشعر أكثر من الحاجة الفعلية 

إن إغلاق DSL هو ضريبة إطار متعددة الوكلاء. لكل DSL مفاهيمها الخاصة، وأدوات التحليل الخاصة بها، ومجتمعها الخاص. بمجرد التزامك، فإن الهجرة مكلفة. رهان Swarm: تخطي DSL بالكامل، واستخدام أداة الدعوة الحالية للنموذج.

> DSL 锁定是多代理 框架税── كل DSL لديه مفهوم خاص به٬ أدوات التدريب الخاصة به٬ مجتمع خاص به٬ عندما تعتمد على التزامك، فإن الانتقال مكلف٬ Swarm 的注: قفز تماما على DSL، باستخدام أدوات التدريب الحالية٬

يضغط السحابة في الاتجاه المعاكس: استخدم القدرة على استدعاء الأدوات التي يمتلكها النموذج بالفعل. تصبح التسليمات دعوات الأدوات. الموسيقي هو أي وكيل يدير الحوار حاليا. الآلة الحكومية متضمنة في طلبات نظام العملاء.

> السحرة 推向相反的方向: استخدام الموديل المتاحة القدرة على استخدام الأدوات.

إنّ المفهوم عميق: لا تحتاج إلى DSL للتنسيق لأنّ LLM هي بالفعل منظّمة. كل دعوة لـ LLM تقرّر ما يجب القيام به بعد ذلك بناءً على السياق. يُعرض التسليمات هذا القرار كوسيلة يمكن أن يُدعيها النموذج.

> 洞察深刻: 你不需要编排 DSL,因为 LLM 已是编排器.                                                                                                                                                                                                                                                    

## مفهوم النواة

### اثنان من البدائيين

**Routine.**إشارة نظامية تحدد دور وكيل وأدوات متاحة. فكر في ذلك مثل مجموعة محددة من التعليمات: "أنت وكيل التجديد؛ إذا سأل المستخدم عن استردادات، تسلم إلى وكيل استرداد".

> **例程。**定义 Agent 角色和可用工具的系统提示──把它想象成一组范围化的指令:"أنت وكيل مختص؛ إذا سأل المستخدم عن استرداد، قم بتوصيل وكيل استرداد".""

**Handoff.**أداة يمكن للعميل أن يطلق عليها التي تعيد كائن عميل جديد. وقت تشغيل السلال يكتشف قيمة العامل العاملة وتبديل العامل النشط للدور التالي.

> **交接。**يمكن استخدام الوكيل، العودة إلى وكيل جديد للموضوع.

هذا هو مجردة كاملة.

> هذا هو المجموعة كلها

```
def transfer_to_refunds():
    return refund_agent  # Swarm sees Agent return → switch active agent

triage_agent = Agent(
    name="triage",
    instructions="Route the user to the right specialist.",
    functions=[transfer_to_refunds, transfer_to_sales, transfer_to_support],
)
```

تُجعل طلب نظام وكيل التجديد يختار التسليم الصحيح بناءً على رسالة المستخدم.

> تُستخدم أداة الـLLM لتنفيذ طريقها حسب المستخدم الذي يختار الاتصال الصحيح.

هذه هي الخطوة المدهشة: إعادة استخدام البنية التحتية الموجودة في النموذج لإستجابة الدعوات الأداة للموسيقى. لا يوجد DSL جديد، لا محرر الرسوم البيانية، لا يوجد آلة الحالة. النموذج يعرف بالفعل كيفية اختيار الأداة المناسبة؛ التسليمات هي أدوات عودة العاملين فقط.

> هذا هو خطوة جميلة: إعادة استخدام أدوات النموذج الحالية لتدوين البنية التحتية. لا يوجد نظام تحرير للكتب الجديد. لا يوجد محرر الرسومات. لا يوجد جهاز تحرير الحالة.

### التجارة بدون جنسية

السجدة غير ذات أساسية صراحة بين الجرائد. يحتفظ الإطار بتاريخ الرسالة خلال الجولة، لكنه لا يستمر في أي شيء. الذاكرة، الاستمرارية، المهام الطويلة الجولة  كل مشكلة المدعو.

> المجموعة بين النشاطات واضحة أن المجموعة غير موجودة.

التصميم غير الحكومي هو متعمد: يجعل الإطار قابلاً لإعادة تشغيل بسيط، قابلاً للتحكم أفقياً، ويمكن إزالة الأخطاء (كل تشغيل مستقل). تكلفة التدفقات العملية الطويلة المشي تتطلب إدارة حالة خارجية (قواعد البيانات والصفوف ومواقع التفتيش).

> 无状态设计是有意的: يجعل الإطار يمكن إعادة تشغيله بسهولة 水平扩展和调调试 (→ التغييرات)  代价是长时间运行的工作流需要外部状态管理 (→ قاعدة البيانات 队列 检查点)

  中文翻译:**需要共享内存的长会话。**交接将对话状态重置为新代理的提示加历史―― بدون حافظة إدارة المستخدم فليس هناك حالة دائمة عبر الوكيل――

## شروط الرئيسية

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Routine / 例程 | "The agent prompt" / "Agent 提示" | System prompt + tool list. Defines role and available handoffs. / 系统提示 + 工具列表。定义角色和可用交接。 |
| Handoff / 交接 | "Transfer to another agent" / "转移到另一个 Agent" | A tool the active agent can call that returns a new Agent. The runtime switches active agent. / 活动 Agent 可以调用的工具，返回新 Agent。运行时切换活动 Agent。 |
| Stateless / 无状态 | "No memory between runs" / "运行间无记忆" | Swarm does not persist anything; memory is the caller's responsibility. / Swarm 不持久化任何东西；内存是调用者的责任。 |
| Active agent / 活动 Agent | "Who's speaking now" / "现在谁在说话" | The agent currently holding the conversation. Handoff changes this. / 当前持有对话的 Agent。交接改变这个。 |
| Context transfer / 上下文传输 | "What moves on handoff" / "交接时传输什么" | Policy for what history the incoming agent sees: full, last N, or summarized. / 传入 Agent 看到什么历史的策略：完整、最后 N 条或摘要。 |
| Handoff loop / 交接循环 | "Agents ping-pong" / "Agent 乒乓" | Failure mode where two agents keep handing back to each other. / 两个 Agent 持续互相交接的失败模式。 |
| OpenAI Agents SDK | "Production Swarm" / "生产 Swarm" | March 2025 successor; adds sessions, guardrails, tracing on top of the handoff primitive. / 2025 年 3 月继任者；在交接原语之上添加会话、防护栏、追踪。 |
| Handoff filter / 交接过滤器 | "Gate on transfer" / "传输门" | SDK feature to inspect and modify context at the handoff boundary. / 在交接边界检查和修改上下文的 SDK 特性。 |

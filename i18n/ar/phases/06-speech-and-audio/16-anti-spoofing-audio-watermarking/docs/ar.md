### أسلوب أسلوب الكشف AASIST و RawNet2 

> AASIST 和 راونيت2  检测模型家族

**AASIST**(2021، تم تحديثه حتى 2026). الاهتمام الرسمي على الخصائص الطيفية. SOTA الحالية على واجب ASVspoof 5 المضادة.

> **AASIST**(2021 年,持续更新至2026 年) ◦ بناء على الوصف المتكرر للاتصالات المميزة.

> **RawNet2。**الموجات الأصلية على الدوام الاول + TDNN 骨干网络──更简单的基线; 微调后仍然有竞争力──

**NeXt-TDNN + SSL features.**2025: إيكابا-طراز + ميزات ويفلم + فقدان التركيز. يصل إلى 0.42% EER على ASVspoof 2019 LA.

> **NeXt-TDNN + SSL 特征。**2025 年变体:ECAPA 风格 + WavLM خصائص + فقدان التركيز──在 ASVspoof 2019 LA 上达到0.42% EER──

### الخطوة الأولى: جهاز كشف أشكال الطيف بسيط (لعبة)

> الخطوة 1: 简单的频谱特征检测器

```python
def spectral_rolloff(spec, percentile=0.85):
    cum = 0
    total = sum(spec)
    if total == 0:
        return 0
    threshold = total * percentile
    for k, v in enumerate(spec):
        cum += v
        if cum >= threshold:
            return k
    return len(spec) - 1

def is_suspicious(audio):
    spec = magnitude_spectrum(audio)
    rolloff = spectral_rolloff(spec)
    return rolloff / len(spec) > 0.92
```

### الخطوة الثالثة: التقييم  الإطار الإقليمي

> الخطوة الثالثة: تقييم  EER ((等错误率)

```python
def eer(real_scores, fake_scores):
    thresholds = sorted(set(real_scores + fake_scores))
    best = (1.0, 0.0)
    for t in thresholds:
        far = sum(1 for s in fake_scores if s >= t) / len(fake_scores)
        frr = sum(1 for s in real_scores if s < t) / len(real_scores)
        if abs(far - frr) < best[0]:
            best = (abs(far - frr), (far + frr) / 2)
    return best[1]
```

## الفخاخ

> 常见陷

- **Watermark without detector ever running.**لا فائدة من ذلك، أرسلي الكاشف في المعلومات
  中文翻译:**嵌入水印但从未运行检测器。**لا معنى لها.
- **Detection without calibration.**أُدرّبُ (أيسست) على عمليات إعادة التأثير في (لوس أنجلوس) ، وتقليل دقة العالم الحقيقي، وتصفّح على مستوى مجالك.
  中文翻译:**检测未校准。**في الولايات المتحدة، تم تدريب AASIST على التأهيل، ومعدلات التأهيل الحقيقية انخفضت.
- **Pitch-shift gap.**تغيير الوضع العنيف يزيل معظم علامات المياه
  中文翻译:**音高偏移漏洞。**激进的音高偏移能去除大多数水印──准备检测作为后备──
- **Metadata strip-and-rehost.**C2PA يمكن تجاهلها بشكل بسيط عن طريق إعادة التشفير. دائماً أضف الدفاع الرموزي + التدقيقي (علامات المائية) معاً.
  中文翻译:**元数据剥离重新托管。**C2PA 通過重新编码即可轻松绕过──始终同时使用加密 + 感知(水印) دفاع──
- **Liveness as detection.**اطلب من المستخدم قول عبارة عشوائية، يمنع هجمات التكرار ولكن لا التنسيق في الوقت الحقيقي.

## شروط الرئيسية

|------|-----------------|-----------------------|
| ASVspoof | The benchmark | Biennial challenge; 2024 = ASVspoof 5. / 双年挑战赛；2024 = ASVspoof 5 |
| CM (countermeasure) | Detector | Classifier: real speech vs synthetic / converted. / 分类器：真实语音 vs 合成/转换语音 |
| SASV | Speaker verif + CM | Integrated biometric + spoof detection. / 集成生物识别 + 欺骗检测 |

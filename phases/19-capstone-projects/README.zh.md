# Phase 19: 毕业项目

> **57 个项目 · ~500 小时 · 🔴高级**

证明你学到了一切。构建作品集级别的系统。

## 学习目标

- 综合运用阶段 01-18 的全部知识，构建完整的生产级 AI 系统
- 在真实场景中实践 Agent 工程、RAG、微调、多 Agent、安全对齐等核心技术
- 建立可展示的作品集项目，覆盖不同技术方向和应用领域
- 深度构建能力：从零实现 Agent 框架、Transformer 训练管线、自动研究系统

## 前置知识

- 完成阶段 01-18 的全部课程学习
- 具备独立设计和实现复杂系统的能力
- 准备投入大量时间（每个项目 25-40 小时）

## 常见困惑

- **57 个项目都要做吗？** → 不需要。建议至少完成 A 组中 2-3 个端到端产品，再选择 1-2 条深度构建路线深入。关键是质量，不是数量。
- **从哪个项目开始？** → 如果目标是 Agent 工程，从 #01（终端编程 Agent）开始；如果目标是 NLP/LLM 研究，从 #30（BPE 分词器）开始；如果想快速出作品集，从 #08（生产 RAG 聊天机器人）开始。
- **每个项目的代码量大概多少？** → A 组产品类项目通常 2000-5000 行 Python；B/C/D 组组件类项目每个 200-800 行；E 组研究类项目合计约 3000-5000 行。

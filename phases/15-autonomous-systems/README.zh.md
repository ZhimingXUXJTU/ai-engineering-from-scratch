# Phase 15: 自主系统

> **22 节课 · ~20 小时 · 🔴高级**

无需人类干预即可运行的 Agent —— 安全地运行。

## 学习目标

- 理解长程 Agent 的挑战：从聊天机器人到自主系统的跃迁
- 掌握自我改进机制：STaR 推理、AlphaEvolve 进化编码、Darwin Godel 自修改 Agent
- 学习安全护栏：终止开关、断路器、金丝雀令牌、成本控制器
- 理解前沿安全框架：Anthropic RSP、OpenAI 准备度框架、DeepMind FSF
- 掌握持久执行、检查点回滚、人机协同（HITL）模式

## 前置知识

- 完成阶段 14（Agent 工程），理解 Agent Loop 和工具调用
- 了解基础分布式系统概念（持久化、容错）
- 熟悉 LLM 安全基础知识（提示注入、越狱）

## 常见困惑

- **自主系统和阶段 14 的 Agent 有什么区别？** → 阶段 14 教你构建单个 Agent 的循环和能力；阶段 15 聚焦于让 Agent 长时间自主运行（小时/天级别）并保持安全——成本控制、终止开关、回滚机制是核心。
- **"自我改进"真的可行吗？** → 课程 02-08 系统梳理了从 STaR（推理链自举）到 AlphaEvolve（进化编码）的真实研究进展和局限，避免过度乐观或过度悲观。
- **为什么安全护栏要占这么多课？** → 自主 Agent 失控的后果远大于普通 LLM。终止开关（课 14）、成本控制器（课 13）、宪法 AI（课 17）是生产部署的必要条件，不是可选项。

# Phase 1: 数学基础

> **22 节课 · ~23 小时 · 🟢入门**

## 学习目标

- 建立线性代数、微积分、概率论的直觉理解，为机器学习打下坚实基础
- 通过代码实现数学概念，而非死记公式
- 掌握优化、降维、信息论等核心数学工具
- 理解数值稳定性、张量运算等工程实现中的数学问题

## 前置知识

- 基础 Python 编程能力（建议先完成 Phase 0）
- 高中数学水平即可，课程会从直觉出发逐步深入

## 常见困惑

- **"数学不好能学 AI 吗？"** → 完全可以。本阶段从直觉出发，用代码理解概念，而非推导证明。重点是理解"为什么"而非"怎么算"。
- **"这么多内容都要学吗？"** → 建议优先学习 01-09 核心课程，其余按需学习。后续阶段用到特定知识时再回来补充。
- **"Julia 还是用 Python？"** → 绝大多数课程使用 Python。少数涉及数学直觉的课程提供 Julia 版本作为补充，Python 版本完全够用。

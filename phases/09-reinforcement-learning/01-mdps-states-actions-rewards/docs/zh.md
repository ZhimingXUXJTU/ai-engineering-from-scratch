# MDP — 状态、动作与奖励

> 马尔可夫决策过程（Markov Decision Process, MDP）包含五样东西：状态、动作、转移概率、奖励函数、折扣因子。强化学习中的一切——Q-learning、PPO、DPO、GRPO——都在这个框架上优化。学会它，读懂整个强化学习就不费吹灰之力。

> **【中文解读】** 马尔可夫决策过程（MDP）包含五个要素：状态、动作、转移概率、奖励函数、折扣因子。RL 中的一切——Q-learning、PPO、DPO、GRPO——都在这个框架上优化。学一次，免费读懂整个强化学习。

> **【拓展：MDP 是 AI 对齐的基础】** ChatGPT 的 RLHF 训练本质上也是一个 MDP：状态=对话上下文，动作=生成的 token，奖励=人类偏好评分。理解 MDP 是理解大模型对齐技术的起点。

## 问题引入

你正在写一个国际象棋机器人。或者一个库存规划器。或者一个交易代理。或者训练推理模型的 PPO 循环。四个不同的领域，一个令人惊讶的事实：它们全部可以归结为同一个数学对象。

监督学习给你 `(x, y)` 对，让你拟合一个函数。强化学习没有标签——只有状态流、你采取的动作和一个标量奖励。那步棋赢了吗？补货决策省钱了吗？交易赚了吗？LLM 刚生成的 token 从评判者那里得到了更高的奖励吗？

你必须先形式化这个数据流，才能从中学习。"我看到了什么"、"我做了什么"、"接下来发生了什么"、"这有多好"——每一项都必须变成你可以推理的对象。这个形式化就是马尔可夫决策过程。本阶段的每个 RL 算法，包括最后的 RLHF 和 GRPO 循环，都在这个框架上优化。

## 核心概念

![马尔可夫决策过程：状态、动作、转移概率、奖励、折扣因子](../assets/mdp.svg)

**五个核心对象。**

- **状态 (State)** `S`。智能体做决策所需的一切信息。在网格世界中是格子位置。在国际象棋中是棋盘状态。在 LLM 中是上下文窗口加上任何记忆。
- **动作 (Action)** `A`。可选的操作。上/下/左/右移动。走一步棋。生成一个 token。
- **转移概率 (Transition)** `P(s' | s, a)`。给定状态 `s` 和动作 `a`，下一个状态的分布。国际象棋中是确定性的，库存管理中是随机的，LLM 解码中几乎是确定性的。
- **奖励 (Reward)** `R(s, a, s')`。标量信号。赢=+1，输=-1。收入减成本。GRPO 中的对数似然比项。
- **折扣因子 (Discount)** `γ ∈ [0, 1)`。未来奖励相对于当前奖励的权重。`γ = 0.99` 对应约 100 步的视野；`γ = 0.9` 对应约 10 步。

**马尔可夫性质 (Markov Property)** `P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`。未来只取决于当前状态。如果不满足，说明状态表示不完整——不是方法的失败，是状态的失败。

**策略与回报。** 策略 `π(a | s)` 将状态映射到动作分布。回报 `G_t = r_t + γ r_{t+1} + γ² r_{t+2} + …` 是未来奖励的折扣和。值函数 `V^π(s) = E[G_t | s_t = s]` 是从状态 `s` 出发、在策略 `π` 下的期望回报。Q 值 `Q^π(s, a) = E[G_t | s_t = s, a_t = a]` 是从特定动作出发的期望回报。每个 RL 算法都在估计这两个量之一，然后据此改进 `π`。

**Bellman 方程。** 本阶段所有方法都使用的不动点方程：

`V^π(s) = Σ_a π(a|s) Σ_{s', r} P(s', r | s, a) [r + γ V^π(s')]`

> **【中文解读】** Bellman 方程是 RL 的核心递推关系：当前状态的价值 = 即时奖励 + 折扣后的下一状态价值。它是动态规划、Q-learning、TD 学习的共同基础。在 LLM 的 RLHF 训练中，这对应于"当前 token 的贡献 = 人类偏好分数 + 未来 token 的期望贡献"。

> **【拓展：从 MDP 到 POMDP】** 现实中很多问题不满足马尔可夫性（当前状态不能完全决定未来），需要用 POMDP（部分可观察 MDP）建模。对话系统就是 POMDP——模型只能看到上下文窗口内的内容，而非完整的用户意图。LLM 的长上下文能力本质上是在缓解 POMDP 的信息不完整问题。
`Q^π(s, a) = Σ_{s', r} P(s', r | s, a) [r + γ Σ_{a'} π(a'|s') Q^π(s', a')]`

这些公式将期望回报拆分为"这一步的奖励"加上"到达位置的折扣值"。递归结构。Phase 9 的每个算法要么迭代这个方程直到收敛（动态规划），要么从中采样（蒙特卡洛），要么自举一步（时序差分）。

## 动手实现

### 第 1 步：一个小型确定性 MDP

一个 4×4 网格世界。智能体从左上角出发，终止状态在右下角，每步奖励 -1，动作集合 `{上, 下, 左, 右}`。参见 `code/main.py`。

```python
GRID = 4
TERMINAL = (3, 3)
ACTIONS = {"up": (-1, 0), "down": (1, 0), "left": (0, -1), "right": (0, 1)}

def step(state, action):
    if state == TERMINAL:
        return state, 0.0, True
    dr, dc = ACTIONS[action]
    r, c = state
    nr = min(max(r + dr, 0), GRID - 1)
    nc = min(max(c + dc, 0), GRID - 1)
    return (nr, nc), -1.0, (nr, nc) == TERMINAL
```

五行代码。这就是整个环境。确定性转移，恒定步惩罚，吸收终止状态。

### 第 2 步：展开一个策略

策略是从状态到动作分布的函数。最简单的：均匀随机。

```python
def uniform_policy(state):
    return {a: 0.25 for a in ACTIONS}

def rollout(policy, max_steps=200):
    s, total, steps = (0, 0), 0.0, 0
    for _ in range(max_steps):
        a = sample(policy(s))
        s, r, done = step(s, a)
        total += r
        steps += 1
        if done:
            break
    return total, steps
```

运行随机策略 1000 次。平均回报大约在 -60 到 -80 之间。最优回报是 -6（直线路径向右下走）。缩小这个差距就是 Phase 9 的全部目标。

### 第 3 步：通过 Bellman 方程精确计算 `V^π`

对于小型 MDP，Bellman 方程是一个线性方程组。枚举所有状态，应用期望，迭代直到值不再变化。

```python
def policy_evaluation(policy, gamma=0.99, tol=1e-6):
    V = {s: 0.0 for s in all_states()}
    while True:
        delta = 0.0
        for s in all_states():
            if s == TERMINAL:
                continue
            v = 0.0
            for a, pi_a in policy(s).items():
                s_next, r, _ = step(s, a)
                v += pi_a * (r + gamma * V[s_next])
            delta = max(delta, abs(v - V[s]))
            V[s] = v
        if delta < tol:
            return V
```

这就是迭代策略评估。它是 Sutton & Barto 书中的第一个算法，也是后续每个 RL 方法的理论基础。

### 第 4 步：`γ` 是有物理含义的超参数

有效视野大约是 `1 / (1 - γ)`。`γ = 0.9` → 10 步。`γ = 0.99` → 100 步。`γ = 0.999` → 1000 步。

太低会让智能体目光短浅。太高会让信用分配变得嘈杂，因为许多早期步骤要分担远期奖励的责任。LLM RLHF 通常使用 `γ = 1`，因为回合短且有界。控制任务使用 `0.95–0.99`。长视野策略游戏使用 `0.999`。

## 常见陷阱

- **非马尔可夫状态。** 如果你需要最近三次观测才能做决策，那么"状态"就不只是当前观测。修复方法：帧堆叠（Atari 上的 DQN 堆叠 4 帧）或使用循环状态（LSTM/GRU 处理观测序列）。
- **稀疏奖励。** 仅赢/输的奖励使大状态空间中的学习几乎不可能。设计奖励塑形（中间信号）或用模仿学习引导（Phase 9 · 09）。
- **奖励黑客行为。** 优化代理奖励通常会产生病态行为。OpenAI 的赛船智能体永远在原地打圈收集道具，而不是完成比赛。始终从目标结果定义奖励，而非代理指标。
- **折扣因子设定错误。** 无限视野任务上 `γ = 1` 使所有值变为无穷大。始终用有限视野或 `γ < 1` 来约束。
- **奖励尺度。** {+100, -100} 与 {+1, -1} 的奖励给出相同的最优策略，但梯度幅度差异巨大。在输入 PPO/DQN 之前归一化到 `[-1, 1]` 附近。

## 用框架实现

2026 年的技术栈在写代码之前，会将每个 RL 管线约化为一个 MDP：

| 场景 | 状态 | 动作 | 奖励 | γ |
|------|------|------|------|---|
| 控制（运动、操作） | 关节角度 + 速度 | 连续力矩 | 任务相关的塑形奖励 | 0.99 |
| 游戏（国际象棋、围棋、扑克） | 棋盘 + 历史 | 合法走法 | 胜=+1 / 负=-1 | 1.0（有限） |
| 库存 / 定价 | 库存 + 需求 | 订购量 | 收入 - 成本 | 0.95 |
| LLM 的 RLHF | 上下文 tokens | 下一个 token | 回合结束时的奖励模型分数 | 1.0（回合约 200 个 token） |
| 推理的 GRPO | 提示 + 部分回复 | 下一个 token | 回合结束时验证器的 0/1 | 1.0 |

在写任何训练循环之前先写好这五元组。大多数"RL 不起作用"的 bug 报告都可以追溯到纸面上 MDP 公式就有问题。

## 练习题

1. **简单。** 在 `code/main.py` 中实现 4×4 网格世界和随机策略展开。运行 10,000 个回合。报告回报的均值和标准差。与最优回报 (-6) 比较。
2. **中等。** 对均匀随机策略，用 `γ ∈ {0.5, 0.9, 0.99}` 运行 `policy_evaluation`。将 `V` 打印为 4×4 网格。解释为什么终止状态附近的值随 `γ` 增大而增长更快。
3. **困难。** 将网格世界变为随机：每个动作以概率 `p = 0.1` 滑向垂直方向。重新评估均匀策略。`V[start]` 变好还是变差？为什么？

## 术语速查表

| 术语 | 通俗说法 | 实际含义 |
|------|----------|----------|
| MDP | "强化学习框架" | 满足马尔可夫性质的元组 `(S, A, P, R, γ)`。 |
| 状态 (State) | "智能体看到的东西" | 在所选策略类下，对未来动态的充分统计量。 |
| 策略 (Policy) | "智能体的行为" | 条件分布 `π(a \| s)` 或确定性映射 `s → a`。 |
| 回报 (Return) | "总奖励" | 从当前步骤开始的折扣和 `Σ γ^t r_t`。 |
| 值 (Value) | "状态有多好" | 从 `s` 出发在策略 `π` 下的期望回报。 |
| Q 值 | "动作有多好" | 从 `s` 出发、以动作 `a` 开始，在策略 `π` 下的期望回报。 |
| Bellman 方程 | "动态规划递推" | 将值 / Q 分解为一步奖励加折扣后续值的固定点公式。 |
| 折扣因子 `γ` | "未来 vs 当前" | 远期奖励的几何权重；有效视野 `~1/(1-γ)`。 |

# 并行/群体/网络架构 | 并行 群体

> 与监督者对比：没有中央决策者。Agent 读取共享事件总线，异步获取工作，写回结果。LangGraph 明确支持"群体架构"用于去中心化、动态环境。Matrix（arXiv:2511.21686）将控制流和数据流都表示为通过分布式队列传递的序列化消息，以消除编排器瓶颈。权衡是明确的：用确定性和可追踪性换取可扩展性。群体适合有许多独立子问题的任务；不适合需要单一连贯计划的任务。

> **【中文解读】** 本节介绍了并行群体网络——大量 Agent 通过共享状态并行工作的组织模式。

> **【拓展：parallel swarm networks→具体应用】** 并行群体网络让大量 Agent 同时处理子任务，然后聚合结果。适合可并行化的任务（如多文件编辑、多数据源查询）。关键挑战是结果聚合——如何合并可能冲突的部分结果。Map-Reduce 是常见的聚合模式。2026 年的实践表明，5-10 个并行 Agent 是最优范围。

## 问题引入

监督者可以扩展到少数工作器。数百个呢？监督者本身成为瓶颈：关于谁做什么的每个决策都通过一个 Agent。一个缓慢的计划步骤会停滞整个系统。

群体架构翻转了设计。没有中央规划者分派工作，工作器从共享队列获取工作。"协调"被烘焙到事件总线语义中。没有编排器；系统扩展直到队列成为瓶颈。

## 核心概念

### 形状

```
              ┌──── 共享队列 ────┐
              │                  │
     ┌────────┼────────┐  ◄──────┬───┘
     ▼        ▼        ▼         │
   工作器  工作器  工作器   工作器
    A       B       C        D
     │        │        │         │
     └────────┴────────┴─────────┘
               │
               ▼
          结果池
```

没有编排器。每个工作器重复：拉取任务、处理、写入结果（并可选地排队后续任务）。

### 何时群体适合

- **许多独立任务。** 抓取、转换、分类。任务之间不互相依赖。
- **可变持续时间的工作。** 如果某些任务需要 100ms 而其他需要 10s，群体会自动平衡负载。
- **吞吐量优先于确定性。** 你关心总完成时间，而非严格排序。

### 何时群体失败

- **有序工作流。** 如果步骤 3 需要步骤 2 的输出，群体可能步骤 2 完成之前就触发步骤 3。
- **全局计划任务。** 复杂的研究问题受益于规划者。一群研究员产生独立的事实，而非连贯的报告。
- **调试。** 没有中央日志和异步工作，重现 bug 是昂贵的。

### Matrix（arXiv:2511.21686）

Matrix 是 2025 年将群体推到自然结论的论文：控制流和数据流都是分布式队列上的序列化消息。没有中央协调者。容错来自消息持久性。可扩展性是消息代理的问题，而非系统的问题。

### LangGraph 的群体架构

LangGraph 2025 文档明确将"群体架构"描述为多 Agent 模式之一：Agent 是节点，但边形成带循环的有向图，任何节点都可以从池中被激活。工作器按条件从可用工作中选择，而非由监督者分配。

### 失败模式：饥饿和热点

如果所有工作器都拉取最快的可用任务，长时间运行的任务只有在成为唯一剩余时才会被获取。经典的队列饥饿。

缓解措施：
- 带显式老化的优先级队列。
- 工作器专业化：某些工作器只接受"长"任务。
- 背压：限制有多少快速任务进入队列。

## 产出物

检查清单：

- **带老化的优先级队列。** 防止长任务饥饿。
- **工作器幂等性。** 任务可能被拉取多次。
- **持久队列。** 生产环境使用 Kafka、Redis Streams。
- **每个任务的可观察性。**
- **背压。**

## 术语速查表

| 术语 | 人们常说的 | 实际含义 |
|------|-----------|---------|
| 群体架构 | "去中心化 Agent" | 工作器从共享队列拉取；没有中央编排器。 |
| 事件总线 | "Agent 订阅主题" | 按类型或内容将任务路由到工作器的消息代理。 |
| 饥饿 | "任务永远不运行" | 低优先级任务因更高优先级工作持续到达而无法被获取。 |
| 热点 | "一个工作器淹没" | 一个工作器获取大部分任务的负载不平衡。 |
| 背压 | "减慢生产者" | 队列填满时向上游发出停止信号。 |
| 幂等工作器 | "安全重跑" | 处理两次产生相同结果的工作器。 |
| 持久队列 | "崩溃后存活" | 磁盘或复制存储支持的队列。 |
| Matrix 框架 | "全消息传递群体" | 数据和控制流都是分布式队列上的序列化消息。 |

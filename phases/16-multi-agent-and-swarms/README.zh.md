# Phase 16: 多 Agent 与集群

> **25 节课 · ~28 小时 · 🔴高级**

协调、涌现与集体智能。

## 学习目标

- 理解多 Agent 系统的四个原语：Agent、交接、共享状态、编排者
- 掌握经典通信协议：FIPA-ACL、言语行为理论、A2A 协议
- 构建协作模式：监督者-工人、分层架构、并行集群、黑板模式
- 学习共识机制与容错：拜占庭容错、投票自洽、辩论拓扑
- 理解群体智能在 LLM 中的应用：PSO、ACO、MARL
- 掌握生产级多 Agent 系统的扩展、故障模式与评估

## 前置知识

- 完成阶段 14（Agent 工程）和阶段 15（自主系统）
- 了解基本的分布式系统概念（共识、容错、消息传递）
- 熟悉至少一个 Agent 框架（LangGraph/AutoGen/CrewAI）

## 常见困惑

- **多 Agent 不是一个 Agent 调用多次吗？** → 不是。多 Agent 的核心价值是分工与专业化——每个 Agent 有独立的上下文、工具和角色。课 01 用四个原语（Agent/交接/共享状态/编排者）解释了为什么多次调用不等于多 Agent。
- **A2A 协议为什么重要？** → Google 的 A2A 协议是 2026 年跨框架互操作的标准尝试。课 12 详细解析了它如何让不同框架构建的 Agent 互相通信。
- **"涌现"是真的吗？** → 课 07（心灵社会）和课 17（生成式 Agent 仿真）展示了在特定条件下，多 Agent 交互确实能产生超越单 Agent 的能力，但也有明显的失效模式（课 23）。

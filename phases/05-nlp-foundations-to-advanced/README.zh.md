# Phase 5: NLP从基础到进阶

> **29 节课 · ~30 小时 · 🟡进阶**

## 学习目标

- 掌握文本预处理、词袋模型、TF-IDF 等基础文本处理方法
- 深入理解词向量（Word2Vec、GloVe）和子词分词的原理
- 学习情感分析、命名实体识别、机器翻译等核心 NLP 任务
- 掌握注意力机制、RAG 检索增强生成等现代 NLP 技术

## 前置知识

- 深度学习基础（Phase 3：神经网络、反向传播、PyTorch）
- 概率论与线性代数基础（Phase 1）

## 常见困惑

- **"有了大模型还需要学传统 NLP 吗？"** → 传统 NLP 方法在低资源场景、可解释性要求高、延迟敏感的生产环境中仍然不可替代。理解传统方法也是理解大模型能力边界的关键。
- **"NLP 和 Transformer 是什么关系？"** → Transformer 是当前 NLP 的主流架构，本阶段覆盖 Transformer 前后的完整 NLP 技术栈。更深入的 Transformer 内容在 Phase 7。
- **"RAG 和普通搜索有什么区别？"** → RAG（检索增强生成）= 检索相关文档 + 用 LLM 生成回答。第 23 课专门讲解分块策略，是构建 RAG 系统的关键。
